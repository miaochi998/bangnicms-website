询盘提交了销售没收到邮件 = **直接丢单**。本节快速排查。

## 1. 询盘邮件没到

**症状**：客户提交了询盘，销售邮箱没收到通知。

**第一步：看后台**

进「询盘」列表 → 找最新的：

- ✅ 看到 → 询盘已存数据库，问题出在**通知**
- ❌ 没看到 → 询盘未提交成功，问题在**前端**

### 询盘存了但邮件没到

**排查清单**：

| 检查 | 怎么看 |
|---|---|
| **垃圾邮件箱** | 让销售看垃圾箱 |
| **SMTP 配置正确？** | 后台「站点设置 → 邮件」点 **测试发送** |
| **发件邮箱密码 / 授权码过期？** | 让运维查 |
| **收件邮箱拒收** | 让收件邮箱加白名单 |
| **后端日志报错？** | 让运维看 |

详见 [邮件通知与 AI 模型](/docs/site-config/email-ai)。

### 询盘没存到

可能：

- **CAPTCHA 验证失败** → 用户没通过
- **防垃圾拦截** → 后台「询盘」"垃圾"列表查
- **后端服务挂** → 让运维查
- **网络中断** → 用户那边问题

## 2. 邮件到了但延迟严重

**症状**：客户提交后 30 分钟才收到邮件。

**可能**：

| 原因 | 解决 |
|---|---|
| **SMTP 服务器慢** | 换专业邮件服务（SendGrid / Mailgun） |
| **邮件队列堵** | 让运维查队列 |
| **反垃圾延迟** | 让 IT 加发件白名单 |
| **服务器负载高** | 让运维扩容 |

**SLA 目标**：< 1 分钟到达。

## 3. 自动回执邮件没到客户

**症状**：客户没收到"提交成功"邮件。

**先排除**：

- 客户**邮箱填错** → 后台核对
- 进了**客户的垃圾箱** → 让客户查
- **客户邮箱被屏蔽**（公司邮箱反垃圾严格）→ 让客户加白名单

**真问题**：

- 自动回执功能**没开** → 后台启用
- 模板**配置错** → 让管理员查

## 4. 企业微信 / 钉钉通知没到

**症状**：销售在企微 / 钉钉没看到提示。

**排查**：

| 检查 | 怎么看 |
|---|---|
| **应用 / 机器人**配置正确？ | 让运维查 webhook |
| **应用被禁用** | 让企微 / 钉钉管理员启用 |
| **AgentID / Secret 过期** | 让运维更新 |
| **网络问题** | 服务器能否访问企微 / 钉钉 API |
| **接收人列表对吗** | 让管理员检查 |

详见 [通知与跟进](/docs/inquiry/notifications)。

## 5. 短信通知没到

**可能**：

- 短信服务商**余额不足**
- 短信**模板审核**未通过
- 收件**手机号格式错**
- 收件人**屏蔽了营销短信**
- 海外手机号**没开通国际短信**

## 6. CRM 未同步

**症状**：询盘提交了，CRM 系统没建 Lead。

**排查**：

| 检查 | 解决 |
|---|---|
| **CRM 集成插件**启用？ | 后台查 |
| **API Key 有效** | 让运维测试 |
| **网络通达** | 服务器能否访问 CRM API |
| **字段映射错** | 让运维查映射配置 |
| **CRM 字段必填** | 看 CRM 是否要求字段你 BangNiCMS 没传 |

## 7. 通知都到了但延迟不一致

**症状**：邮件 1 分钟到，企微 10 分钟到。

**可能**：

- 企微 webhook **限流**
- 企微 / 钉钉服务**当前繁忙**
- 后端**通知顺序错乱**（应该并行的串行了）

让开发者优化为并发发送。

## 8. 测试时通知都到，正式上线后不到

**典型差异**：

- 测试用**测试邮箱**（可能加了白名单）→ 真实客户邮箱被反垃圾拦
- 测试在**测试服务器**（IP 信誉好）→ 生产服务器 IP 被列黑名单
- 测试时**配额够**（生产时配额用完）

**解决**：

- 让运维**配 SPF / DKIM / DMARC**（邮件信任）
- 用专业邮件服务（不要用 Gmail / QQ 个人邮箱发）
- 监控配额

## 9. 通知突然全部失败

**典型原因**：

- 邮箱**密码 / 授权码过期**（多数 6 月-1 年）
- API Key 被**误吊销**
- 服务商**故障**（看其他客户是否也挂）
- 网络**阻断**（服务器 IP 被封）

**应急**：

- **快速切换**到备用邮件服务（让运维准备好）
- **手动监控**询盘并提醒销售（暂时通过其他方式）
- **联系**服务商

## 10. 通知信息不完整

**症状**：邮件 / 企微只显示部分信息。

**可能**：

- 通知**模板**只配置了部分字段
- 字段**数据为空**（用户没填）
- 模板**字符截断**（如某邮件客户端只显示前 100 字）

让运维 / 开发者优化模板。

## 测试通知健康度

**每周自动跑一次**：

- 后台「站点设置 → 邮件」→ **发送测试邮件**
- 用前台无痕模式提交一条测试询盘
- 检查每个通道是否到位

**自动化监控**：

- 让运维写**心跳脚本**：每天凌晨自动发一封测试 → 失败时报警
- 让你**第一时间**发现通知挂了
