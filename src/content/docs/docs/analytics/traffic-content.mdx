数据告诉你**用户喜欢什么、不喜欢什么**——基于此调整内容策略，让爆款更爆、长尾减负。

## 关键指标

| 指标 | 含义 | 行业基准 |
|---|---|---|
| **PV**（页面浏览量） | 总浏览次数 | 看绝对值趋势 |
| **UV**（独立访客） | 不重复用户数 | 是 PV 的 1/2 - 1/4 |
| **平均停留时长** | 用户停在页面的时间 | > 2 分钟为良好 |
| **跳出率** | 只看一页就走的访客比例 | < 60% 为良好 |
| **每访问页数** | 平均一次访问看多少页 | > 3 页为良好 |

```
5    行业洞察：激光切割技术演进   700    500  4:30   30%   2
```

**洞察**：

- **IS-2026 是爆款**（PV + 询盘双高）→ 加大推广预算、写更多关联文章
- **关于我们** PV 高但询盘极少 → 正常（建立信任的页）
- **联系我们**询盘最高 → 入口设计有效
- **行业洞察文章**停留时长最长 → 内容质量高，值得写更多

## 流量趋势

**典型趋势图**（按日 / 周 / 月）：

```
PV 趋势（最近 30 天）
3000 ┤            
2500 ┤        ╭──╮
2000 ┤   ╭──╮ │  ╰─╮
1500 ┤───┤  ╰─┤    ╰────
1000 ┤   
 500 ┤   
   0 └────────────────────
     1  5  10 15 20 25 30
```

**怎么解读**：

- **持续上涨** → SEO 投入有效、市场需求增长
- **平稳** → 业务稳定，关注转化率
- **下跌** → 警报，立刻排查（搜索引擎降权？季节性？）
- **暴涨**（2 倍以上）→ 可能是机器人攻击或某个内容刷屏

## 来源分析

**主要来源**：

| 来源 | 含义 | 优化方向 |
|---|---|---|
| **搜索引擎**（Google / 百度） | SEO 流量 | 持续 SEO 投入 |
| **直接访问** | 用户直接输 URL / 收藏夹 | 提升品牌认知 |
| **社交媒体** | 微信 / X / LinkedIn | 内容营销 |
| **推荐**（Referer） | 其他站点链过来 | 友链 / PR |
| **广告** | SEM / Display | 投放优化 |
| **邮件** | 邮件订阅点击 | 邮件营销 |
| **其他** | 无法识别 | 通常是机器人 |

**典型 B2B 站来源占比**：

- 搜索引擎 50-70%
- 直接访问 15-25%
- 社交 5-10%
- 推荐 5-10%
- 广告 0-15%（取决于投放）

## 关键词分析（搜索流量）

**问题**：搜索引擎给你的流量来自什么关键词？

**数据来源**：

- **内置**：仅能看 Referer 中的关键词（多数现代搜索引擎已加密 = 看不到）
- **Google Search Console**（强烈推荐）：完整关键词数据
- **百度站长**：中国大陆关键词

详见 [整合 GA / GSC](/docs/analytics/external-integration)。

## 跳出率分析

**跳出率高 = 用户进了一页就走**——可能原因：

| 原因 | 怎么看 | 怎么改 |
|---|---|---|
| **加载慢** | 看 Lighthouse / GA 加载时间 | 优化图片、CDN |
| **内容不匹配** | 看搜索关键词 vs 实际内容 | 改 SEO / 内容 |
| **设计差** | 看用户截图 / 录像（Hotjar） | 改设计 |
| **内容太短** | 看停留时长 < 30s | 加深度 |
| **没引导** | 看 CTA 点击率 | 加 CTA |

## 多语言版本对比

**典型对比**：

| 语言 | UV | 询盘 | 转化率 | 站点排序 |
|---|---|---|---|---|
| 中文 | 5000 | 80 | 1.6% | 主市场 |
| 英文 | 3000 | 30 | 1.0% | 第二市场 |
| 日文 | 800 | 5 | 0.6% | 探索市场 |
| 德文 | 200 | 1 | 0.5% | 长尾 |

**洞察**：

- **中文**最高转化 → 主战场
- **英文**有量但转化低 → SEO + 落地页本地化
- **日文 / 德文**长尾 → 维持低投入

## 设备 / 浏览器

**典型分布**：

```
移动端 60%（Android 35% + iOS 25%）
PC     35%（Chrome 25% + Edge 5% + Safari 3% + 其他）
平板   5%
```

**洞察**：

- 多数访客在**手机**上看你的站 → 优先优化移动体验
- 桌面浏览器 95% 是 Chromium 系 → 不用兼容老 IE
- 平板少 → 不用专门优化

## 实时数据

**实时仪表盘**通常显示：

- 当前在线人数
- 最近 1 小时 PV
- 当前热门页（Top 5）
- 最近询盘提交
- 实时转化事件

**用途**：

- 大促 / 营销活动期间盯效果
- 异常监控（流量暴跌时立刻发现）

## 内容策略调整

基于数据决定：

### 加大投入

- **PV 高 + 转化高**的内容 → 写更多关联内容
- **关键词排名上升**的页 → 加大 SEO 投入
- **新写的高互动文章** → 推广

### 优化

- **PV 高但跳出率高** → 改内容 / 改 CTA
- **PV 低但停留长** → SEO 优化让更多人看到
- **关键词排名下降** → 内容更新

### 砍掉

- **PV 极低 + 长期不增长**的页 → 合并或删除
- **重复内容** → 整合

## 内容生命周期

每篇文章的典型流量曲线：

```
PV
 ↑
 │ 发布初期：从 0 涨到 100
 │ 1-2 周：达到峰值
 │ 1-3 月：缓慢下降
 │ 半年-1 年：稳定低位（长尾流量）
 └────────────────────────→
   1d  1w  1m  3m  6m  1y
```

**SEO 长尾**让老内容**持续带流量**——这就是为什么 B2B 内容站值得长期投入。

## 何时看流量数据

| 频率 | 看什么 |
|---|---|
| **每天** | PV 是否正常（异常告警） |
| **每周** | Top 10 内容 + 来源分布 |
| **每月** | 月度趋势 + 内容策略调整 |
| **每季度** | 漏斗 + 多语言对比 |
| **每年** | 年度复盘 + 来年规划 |

## 常见问题

### 流量突然暴涨是好事吗？

**不一定**——

- 真实原因（爆款内容、社交刷屏、广告投放）→ 好事
- 异常原因（机器人攻击、刷流量）→ 立刻排查

排查：

- 看来源是否突变（如全部来自一个 IP）
- 看跳出率是否极高（机器人特征）
- 看 GA 中的"无效流量"

### 我能看具体某个用户的访问路径吗？

**内置不行**（隐私考虑）。

需要：

- **GA4** 提供"User Explorer"
- **Hotjar / Clarity** 提供录像

详见 [整合外部工具](/docs/analytics/external-integration)。

### 内容删除了流量数据保留吗？

**保留**（PageView 表独立存）—— 但报表里看不到内容标题（因为内容已删）。

如果业务需要"删了内容也能看历史数据"，让运维定期把内容标题 snapshot。

### 多语言版本算同一篇还是不同篇？

**默认算不同篇**——中英文版本各自统计。

如果想"看一篇的合并流量"，需要让开发者扩展报表。
