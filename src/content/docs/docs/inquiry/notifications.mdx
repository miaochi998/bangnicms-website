询盘的**响应时长**直接决定成交率——客户提交后**1 小时内**得到响应，成交率提升 50%。本节配置实时通知。

## 多通道通知

最佳实践 = **多通道并行**：

```
访客提交询盘
  ↓
[同时] 4 个通道：
├─ ① 邮件 → 销售邮箱（标准方式）
├─ ② 企业 IM 推送 → 企微/钉钉/Slack（实时）
├─ ③ 短信 → 销售手机（重要客户用）
└─ ④ CRM 系统 → 自动建 Lead（数据归档）
```

每通道有独立优势：

| 通道 | 优势 | 劣势 |
|---|---|---|
| **邮件** | 标准、稳定 | 销售看不及时 |
| **企微 / 钉钉** | 实时、可对话 | 需要企业 IM 部署 |
| **短信** | 必看 | 收费、字数限制 |
| **CRM** | 自动归档 | 通常没有"实时"反馈 |

## 邮件通知

**最基本**——必须配置。详见 [邮件通知与 AI 模型](/docs/site-config/email-ai)。

### 多收件人

让运维在 [站点设置 → 邮件](/docs/site-config/email-ai#询盘邮件通知) 配：

- **主收件**：`sales@example.com`（销售经理团队组邮）
- **抄送**：`ceo@example.com`（CEO 关注）/ 销售总监

### 自动给客户发回执

详见 [询盘表单设置 - 自动回执邮件](/docs/inquiry/form-settings#自动回执邮件)。

让客户**立刻收到确认邮件**——比销售跟进还重要：

- 让客户知道"提交成功"
- 提升专业感
- 防止客户找其他供应商

## 企业 IM 推送

**主流方案**：

### 企业微信

通过插件 + 企业微信开放 API：

<Steps>

1. 让运维在企业微信后台**注册一个应用**

2. 拿到 **AgentID + Secret**

3. 后台「插件 → 企业微信通知」配置：
   - AgentID
   - Secret
   - 接收人列表（销售微信工号）

4. 测试发送 → 确认到达

</Steps>

**优势**：

- 销售实时看到（手机 / PC）
- 可以**直接对话**询盘客户（如果接通了客户微信）
- 支持卡片消息

### 钉钉

类似——让运维注册钉钉机器人 → 拿 webhook → 配到插件。

### Slack

跨国团队常用：

- 创建 Slack App
- 拿 webhook
- 配到 BangNiCMS 插件
- 询盘提交时自动 post 到指定 channel

## 短信通知

**适合**：

- VIP 询盘（关键大客户）
- 销售在外、不在 IM
- 重要节点（成交、流单风险）

**实现**：

- 接短信服务商（阿里云、腾讯云、Twilio）
- 通过插件触发

**成本**：每条短信 0.05-0.5 元，按量付费。

**别滥用** —— 只在真正紧急时发短信，否则销售会屏蔽。

## CRM 集成

**目的**：询盘 → 自动建为 CRM Lead，归档客户全生命周期。

### 主流 CRM

| CRM | 适合 |
|---|---|
| **Hubspot** | 全球 B2B 标准 |
| **Salesforce** | 大企业 |
| **销售易 / 纷享销客** | 中国本土企业 |
| **企业微信 + 客户联系** | 中小企业，免费 |
| **自建 CRM** | 极特殊需求 |

### 集成方式

通过插件：

```
BangNiCMS 询盘提交
  ↓
插件触发 webhook
  ↓
CRM 接收 → 自动建 Lead
  ↓
分配给销售 → 跟进
```

**字段映射**：

| BangNiCMS | CRM (Hubspot 例) |
|---|---|
| 联系人姓名 | First Name + Last Name |
| 邮箱 | Email |
| 电话 | Phone |
| 公司 | Company |
| 需求描述 | Notes |
| 来源页面 | Lead Source |
| 来源关键词 | Original Source Drill-Down |

## 自动跟进规则

**SLA 自动提醒**——超时未响应自动升级：

```
规则 1：新询盘 1h 内未接单
  → 邮件提醒：所有销售
  → 钉钉提醒：销售经理

规则 2：跟进中 24h 内无新跟进
  → 邮件提醒：负责销售
  → 第二次（48h）→ 销售经理

规则 3：跟进 7d 后无成交
  → 标记"风险"
  → 邮件提醒：销售总监
```

**当前需要插件支持** —— 让开发者实现 SLA 引擎。

## 通知频率控制

避免**通知轰炸**：

- ❌ 每条询盘都给所有销售发 → 销售会屏蔽
- ❌ 重要 + 不重要混杂 → 关键消息被淹没

**最佳做法**：

- **新询盘** → 主收件销售 + 销售经理（2 人）
- **超时未跟进** → 加上销售总监
- **VIP 询盘**（标 🔥 标签）→ 单独短信通道
- **垃圾询盘** → **不通知**（直接归档）

## 测试通知

**配好后立刻测试**：

<Steps>

1. **手动发测试邮件**——后台「站点设置 → 邮件」点 **发送测试邮件**

2. **手动模拟询盘提交**：
   - 用浏览器无痕模式打开前台
   - 填表单（用真实邮箱）
   - 提交

3. **检查每个通道**：
   - 销售邮箱：收到了吗？
   - 企微 / 钉钉：弹通知了吗？
   - CRM：建 Lead 了吗？

4. **回执邮件**：客户邮箱收到回执了吗？

5. **5 分钟内全到位** → 配置成功

</Steps>

## 紧急情况：通知没到

排查清单：

| 检查 | 怎么看 |
|---|---|
| 邮箱配置正确？ | 测试发送邮件确认 |
| 收件邮箱是否进垃圾箱？ | 看垃圾邮件 |
| 服务器能访问外网？ | 让运维 ping smtp 服务器 |
| 企微 / 钉钉 webhook 有效？ | 让运维测试 webhook |
| CRM API Key 有效？ | 让运维查 |
| BangNiCMS 后端日志有错？ | 让运维看日志 |

询盘**已经存到数据库**（提交 → DB 是最优先）→ 即使通知失败，**询盘数据不会丢**。

## 何时调整通知

| 时机 | 调什么 |
|---|---|
| **销售团队扩张** | 加新成员到收件列表 |
| **响应时长不达标** | 接更多通道（短信 / 钉钉） |
| **询盘量爆增** | 加 SLA 自动分配规则 |
| **CRM 上线** | 接 CRM 集成 |

## 常见问题

### 我能给不同来源的询盘配不同收件人吗？

可以——通过**询盘类型 / 来源 / 国家**等字段路由：

- 产品 A 的询盘 → 销售小组 A
- 合作咨询 → 商务部
- 北美询盘 → 北美销售

需要插件 / 主题层面实现路由规则。

### 询盘自动分配给销售后，销售可以拒绝吗？

**通常可以**——销售在后台点"转单 / 退回未分配"。

但**频繁退回**会被销售经理关注（懒惰 / 拒接信号）。

### 通知里能附产品图 / 报价单吗？

**邮件**可以——附图片 / 文件附件。

**企微 / 钉钉**支持卡片消息（图 + 文）。

让开发者扩展插件实现。

### 我能定制通知模板吗？

**当前后台 UI 不暴露模板编辑**——通常通过主题或插件代码硬编码。如有需求让开发者扩展为"可视化模板编辑"。

### 海外销售收不到邮件（被反垃圾拦了）？

让运维：

- 配 SPF / DKIM / DMARC（让发件邮箱被信任）
- 用专业邮件服务（SendGrid / Mailgun）
- 让海外销售把发件邮箱加白名单
