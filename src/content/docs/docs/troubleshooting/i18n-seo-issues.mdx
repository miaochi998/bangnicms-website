多语言与 SEO 问题影响**国际市场流量**——必须定期排查。

## 1. 切换语言后看到的还是默认语言

**症状**：从中文切到英文，看到的还是中文。

**可能**：

| 原因 | 怎么验证 |
|---|---|
| **该页没翻译** | 后台编辑页看英文 Tab 是否填了 |
| **fallback 机制启动** | 系统自动用默认语言（这是正常 fallback） |
| **URL 切了但页面没刷新** | F5 看 |
| **浏览器 cookie 卡住语言** | 清 cookie / 无痕模式 |

**正常的 fallback**：

- 英文版的内容字段为空 → 显示中文（避免空白）
- 标记为「**待翻译**」或「**未开始**」状态 → 不在英文站显示

详见 [翻译工作流](/docs/i18n/translation-workflow)。

## 2. URL 不带语言前缀

**症状**：英文版 URL 应该是 `/en/about-us`，实际是 `/about-us`。

**可能**：

- **默认语言是英文**（默认语言永远是裸 URL，不带前缀）
- URL 策略**配错**

详见 [URL 策略与语言段](/docs/i18n/url-strategy)。

## 3. hreflang 标签缺失 / 错误

**症状**：搜索引擎不知道多语言版本对应关系。

**怎么看**：

- 浏览器 F12 → Elements 看 `<head>`
- 应该有：`<link rel="alternate" hreflang="..." href="..." />`

**正常**：每种语言一个 + 一个 `x-default`。

**异常**：

- 缺少 → 主题代码 bug，让开发者修
- href 错（指向不存在的页）→ 主题或 URL 配置问题

## 4. Google Search Console 报"重复内容"

**症状**：SC 警告"多个 URL 指向相同内容"。

**可能**：

- 中英文内容**完全相同**（运营没翻译，全是中文 fallback）
- 结构化数据声明错
- canonical 标签错

**解决**：

- 完成翻译
- 让开发者检查 canonical / hreflang

## 5. 某语言版本不被收录

**症状**：英文版本搜不到，但中文版可以搜到。

**可能**：

- 英文版**还没被爬虫抓**（新加语言 1-2 周内常见）
- 英文版的 `noindex` 标签错位
- robots.txt 屏蔽了 `/en/*`
- **所有英文页都为空**（没翻译） → 搜索引擎认为低质量不收录
- 站点 sitemap **没包含**英文版

**解决**：

- 在 Search Console **提交英文 sitemap**
- 完成英文翻译
- 让运维检查 robots.txt

## 6. 默认语言改了之后旧 URL 失效

**症状**：把默认语言从中文改成英文 → 旧的 `/about-us` 现在指英文，原中文跳到 `/zh/about-us`。

**这是正常的**——默认语言永远裸 URL。

**修复 SEO 影响**：

- **运维配 301 重定向**：旧 URL → 新 URL
- Search Console 提交"地址变更"

详见 [域名与 URL 策略 - 切换默认语言](/docs/site-config/domain-url-strategy#切换默认语言的安全流程)。

## 7. AI 翻译质量差

**症状**：英文翻译看着像机器人写的、不自然。

**可能**：

- 用了**质量低的 AI 模型**（如老版 GLM 而不是 GPT-4）
- 没设**翻译提示**（aiHint）
- **专业术语**没指明
- 长文翻译**上下文丢失**

**改进**：

- 升级到 GPT-4 / Claude 3.5 Sonnet
- 加术语提示
- 关键内容**人工修订**

详见 [AI 翻译](/docs/ai/translation)。

## 8. 翻译进度仪表盘数据不准

**症状**：仪表盘说"60% 完成"，实际看上去不只这么多。

**可能**：

- 仪表盘统计**只算特定字段**（如标题 + 描述）
- **缓存没刷新**
- 计算口径问题

让运维 / 开发者核对统计逻辑。

## 9. 复制翻译后看不到副本

**症状**：点了"从默认语言复制" → 没生成副本。

**可能**：

- 复制操作**失败**（看后端日志）
- **没有内容可复制**（默认语言下没东西）
- **副本已存在**（系统跳过避免覆盖）
- 浏览器缓存 → 硬刷新

详见 [翻译工作流 - 复制翻译](/docs/i18n/translation-workflow#冷启动捷径从默认语言复制翻译)。

## 10. SEO 字段没生效

**症状**：改了 SEO 标题但搜索结果显示的还是旧的。

**SEO 数据延迟**：

- **Google**：1-7 天重新抓取
- **百度**：1-30 天

加速：

- Search Console **请求重新抓取**
- 提交更新后的 sitemap
- 内容主动推送（百度站长平台）

## 11. og 图分享时显示不对

**症状**：把 URL 分享到微信 / X，缩略图错 / 没有。

**可能**：

- og 图**没设**（用了主题默认）
- 分享平台**缓存了旧 og 图** → 用平台的"刷新缓存"工具
- og 图**尺寸 / 格式错**（应 1200x630 PNG/JPG）

**调试工具**：

- Facebook：Sharing Debugger
- Twitter Card Validator
- 微信调试器（无官方，靠经验）

## 12. 多语言 URL 之间互相跳转 404

**症状**：从中文站点击切到英文 → 404。

**可能**：

- **该页没英文版**（没翻译） → 主题应该 fallback 到默认语言而不是 404
- 主题逻辑 bug
- URL 配置错

让开发者查主题的语言切换逻辑。
