后台「内容」菜单下的 5 个子菜单——**页面、产品、文章、下载、分类**——是你 90% 时间会待的地方。这一篇带你建立全局印象：每种内容是什么、什么时候用、它们怎么互相关联。

后台入口：**内容** 菜单（左侧导航最上方一组）

<Screenshot caption="后台左侧「内容」菜单展开" hint="展示页面 / 产品 / 文章 / 下载 / 分类 / 菜单 / 媒体库 / 内容模型 这一整组" />

## 5 种内容怎么选

| 这是什么内容 | 用哪个 |
|---|---|
| 首页、关于我们、联系我们、隐私政策（**独一无二的固定页**） | 页面 |
| 你卖的商品、设备、服务（**有详情页 + 询盘表单**） | 产品 |
| 行业洞察、博客、新闻、案例（**按时间序的长文**） | 文章 |
| PDF 资料、白皮书、安装包、CAD 图纸（**给用户下载**） | 下载 |
| 给上面 4 类内容打的标签（**不是独立内容**） | 分类 |

**判断诀窍**：

- 「同类只有一个」 → **页面**（如就一个「关于我们」）
- 「同类有很多 + 你想卖」 → **产品**
- 「同类有很多 + 你想发表观点」 → **文章**
- 「主要让用户下载文件」 → **下载**

举个常见误区：「2026 年新品介绍」该用产品还是文章？

- 如果是**一款具体的新品**（用户能询盘购买） → 产品
- 如果是**对系列新品的整体介绍**（用户读完去看产品列表） → 文章

## 它们是怎么连起来的

一个完整的 B2B 站点典型结构：

```
首页（Page: home）
  ├─ 顶部 Header 菜单 ───→ 产品中心、关于我们、联系我们
  └─ 主区
       ├─ 精选产品（来自勾选了「首页精选」的 Product）
       ├─ 行业洞察（来自最新 Article）
       └─ Hot Downloads（来自最新 Download）

产品详情页（Product: x500-laser-cutter）
  ├─ 询盘表单 ───→ 询盘绑定到该产品
  ├─ 相关产品（同分类的其他 Product）
  └─ 相关下载（同分类的 Download）

文章详情页（Article: 2026-laser-trends）
  └─ 相关文章（同分类的其他 Article）

分类聚合页（Category: industrial-equipment）
  └─ 该分类下的所有产品 / 文章 / 下载
```

「分类」是把 5 类内容串起来的胶水——**先建好分类**，给每条产品 / 文章 / 下载贴上标签，前台的"相关推荐"和"分类聚合页"才能自动工作。

## 共同的字段

虽然 5 类内容不一样，但它们**有几个一定会填的共同项**：

- **唯一键**：决定网址（如 `about-us`、`x500-laser-cutter`）。**保存后改会让旧网址失效**
- **标题**：这个内容叫什么
- **状态**：草稿 / 已发布 / 已停用（前台只能看到已发布的）
- **多语言**：每种语言独立填一份
- **SEO 标题 / SEO 描述**：搜索引擎看到的标题和描述（不填则用默认标题与摘要）

后续每篇会详细说每种内容**额外**有什么字段。

<Aside type="note">
**为什么 BangNiCMS 没有「关键词（meta keywords）」字段？**

因为 Google 在 2009 年就公开声明 `<meta keywords>` 不影响排名了，**继续填等于浪费时间**。其他主流搜索引擎也基本一致。
</Aside>

## 三种状态

每条内容（除了分类）都有三种状态：

- **草稿** — 前台看不到。新建默认就是这个
- **已发布** — 前台可以看到
- **已停用** — 前台看不到，但所有内容保留。后续可以重新发布

**已发布**的内容**不能直接退回草稿**——这是为了防止误操作让上线内容下线。需要"暂时下线"请用「停用」。

## 多语言怎么管

如果你的站点有多种语言（如中英文），每条内容**每种语言独立填一份**。

- 编辑页右上角有**语言 Tab 切换器**
- 每个 Tab 上有「翻译状态」徽章：未开始 / 进行中 / 待翻译 / 待确认 / 已完成
- 只有标记**已完成**的语言版本，前台才会显示
- 没翻译的语言**前台自动隐藏**——访问该语言地址会 404 或回退到默认语言，不会出现"中英混排"的尴尬

详见 [多语言总览](/docs/i18n/overview)。

## 常见问题

### 我能跳过分类直接建产品吗？

可以——「分类」字段是**可选**的。但跳过分类意味着：

- 前台没有"产品分类页"（用户只能看完整列表）
- 详情页的"相关产品"模块退化为"随便推荐"（按更新时间）
- 失去与「下载」的自动关联（无法在产品页底部展示对应资料）

强烈建议**至少建 3-5 个一级分类**再开始建产品。

### 我建的内容前台访问不到怎么办？

依次检查：

1. 状态是不是**已发布**？草稿前台看不到
2. 当前语言版本的「翻译状态」是不是**已完成**？没翻译的语言前台不显示
3. 网址（唯一键）拼对了吗？区分大小写、连字符不能漏
4. 还是不行 → 按 F12 打开开发者工具，看 Network 标签是否有 4xx/5xx 报错，截图发给运维

### 内容之间能复制吗？

部分支持：

- **下载**：列表页每行有「克隆」按钮 → 一键复制全部字段（除唯一键自动加 `-copy` 后缀）
- **产品 / 文章**：当前需要手动新建后复制粘贴主要字段（克隆功能在路上）
- **页面**：通常是独一无二的，不需要克隆

### 已经发布过的内容删了会怎样？

外部友链、搜索引擎收录都会失效（变 404）。**强烈建议**：

1. 先把状态改成**已停用**，前台立刻不可见但保留数据
2. 观察 30 天确认没有外部访问
3. 让运维配置 301 重定向到替代地址
4. 最后再删

详见各章节的「删除」段落。
