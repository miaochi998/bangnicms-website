后台入口：**数据统计** 菜单

## BangNiCMS 内置统计 vs 第三方工具

| 维度 | 内置（PageView） | 第三方（GA4 / 百度统计 / Matomo） |
|---|---|---|
| **流量趋势** | ✅ 基础 | ✅ 详细 |
| **来源分析** | ✅ Referer | ✅ UTM / 关键词 / 渠道 |
| **行为热图** | ❌ | ✅（如 Hotjar） |
| **漏斗分析** | ❌ | ✅ |
| **A/B 测试** | ❌ | ✅（如 Google Optimize） |
| **隐私** | ✅ 数据自主 | ⚠️ 数据上送 Google |
| **成本** | 免费 | 免费 / 收费 |

**最佳实践**：

- **内置** + **GA4 / 百度统计**并用
- 内置看**站内业务数据**（询盘 / 内容表现）
- 第三方看**用户行为细节**

## 内置统计能告诉你什么

### 1. 流量数据

- 每日 / 每周 / 每月 PV、UV
- 流量趋势（涨 / 跌）
- 同比 / 环比

### 2. 内容表现

- 哪些产品 / 文章访问最多
- 哪些页面停留时间长
- 哪些跳出率高

### 3. 来源分析

- 直接访问 / 搜索引擎 / 社交 / 广告
- 哪些关键词带流量
- 哪些外站给你发友链

### 4. 转化数据

- 询盘提交数（详见 [询盘转化分析](/docs/inquiry/conversion-analytics)）
- CTA 点击数
- 订阅 / 下载数

### 5. 多语言数据

- 哪种语言版本最多人访问
- 各语言版本的转化率
- 跨语言访问行为

## 数据看板的几个常用页

进「数据统计」后，左侧导航通常有：

- **总览** — 顶层数字
- **流量** — 详细流量数据
- **内容** — 内容表现排行
- **来源** — 来源细分
- **询盘** — 转化漏斗
- **SEO** — 搜索引擎数据
- **多语言** — 语言版本对比

## 何时看数据

**频率建议**：

| 角色 | 频率 | 看什么 |
|---|---|---|
| **运营** | 每天 | 当日流量、新询盘 |
| **运营经理** | 每周 | 周报、本周对比上周 |
| **总监** | 每月 | 月报、趋势、漏斗 |
| **CEO** | 每季度 | 季度增长、KPI 完成度 |

## 常见问题

### 内置统计的数据准吗？

**基础数据准**——PageView 表逐条记录访问。

但**用户行为细节不准**：

- 内置的"UV"是基于浏览器指纹粗估，**不如 GA4 准**
- 时长统计依赖前端心跳，**网络抖动会丢数据**

**建议**：核心 KPI（PV / 询盘）看内置，行为细节看 GA4。

### 数据保留多久？

**永久保留**（只要数据库还在）。但旧数据查询会变慢。

让运维**定期归档**：

- < 90 天：在线热数据
- 90 天-1 年：温数据（在线但不索引）
- > 1 年：冷数据（归档表）

### 我能导出数据做 BI 分析吗？

可以——后台支持**导出 CSV / Excel**。或让运维直连数据库给 BI 工具。

详见 [整合外部工具](/docs/analytics/external-integration)。
