「页面」用来管站点上**身份固定、独一无二**的几张内容——首页、关于我们、联系我们、服务条款、隐私政策……

如果一个内容**同类有很多条**（比如博客、新品介绍），那是**文章**或**产品**，不是页面。

后台入口：**内容管理 → 页面**

<Screenshot caption="后台「页面管理」列表页全貌" hint="展示列表 + 右上角「新建页面」按钮 + 每行的状态/语言徽章" />

## 新建一个页面

<Steps>

1. 点页面列表右上角的 **新建页面**

   <Screenshot caption="新建页面表单（路径键 + 页面标题 + 副标题等）" hint="突出必填项的红色标记与字段说明" />

2. 填两个必填项：
   - **路径键**：决定网址。英文小写、用连字符隔开。比如 `about-us`、`services`。**保存后再改会让旧网址失效**，要慎重
   - **页面标题**：就是这个页面的主标题。比如「关于我们」

3. （可选）填**副标题**和**摘要**
   - 副标题：首屏 hero 区下方那行小字
   - 摘要：用来给搜索引擎、社交分享、卡片预览用

4. 在富文本编辑器里写**正文**
   - 支持插图、视频、按钮、表格
   - 图片直接拖进去就上传

5. 点 **保存草稿**

   保存后页面状态是「草稿」，**前台还看不到**。

6. （可选）切换右上角的语言 Tab，翻译成其他语言

7. 全部填好后，点 **发布**

   状态变成「已发布」，前台立即能访问。

</Steps>

## 三种状态

<Screenshot caption="页面编辑页右上角的状态切换器" hint="展示「草稿 / 已发布 / 已停用」三个选项及当前选中态" />

页面有三种状态，用右上角的状态切换器调整：

- **草稿** — 前台看不到。新建默认就是这个
- **已发布** — 前台能看到
- **已停用** — 前台看不到，但所有内容保留。后续可以重新发布

**注意**：已发布的页面**不能直接退回草稿**——这是为了防止误操作把上线页面下线。如果需要"暂时下线"，请用「停用」。

## 首页是哪个页面？

约定：**路径键填 `home` 的页面就是首页**。

- 用户访问 `https://你的站点.com/` 时，系统自动找路径键是 `home` 的页面
- 如果你想换首页，把当前首页的路径键从 `home` 改成别的（如 `old-home`），把新的页面路径键设为 `home`

## 系统关键页

<Screenshot caption="系统关键页徽章与「高级设置」开关" hint="编辑页顶部红色「系统关键页」徽章，与底部高级设置内的开关" />

首页、关于我们、隐私政策这类页面，**删了会让站点崩溃**——外部友链、搜索引擎都还指向它们。

BangNiCMS 给这些页面提供了「系统关键页」标记保护：

- 编辑页右上角能看到 **系统关键页** 红色徽章
- 即使停用了也**不能删除**——必须先取消这个标记才能删

**典型流程**：

1. 编辑页面 → 找到底部「高级设置」→ 关闭「系统关键页」开关 → 保存
2. 把页面状态改成「已停用」
3. 再回来点删除

刚装好系统时，**首页（`home`）/ 关于我们（`about-us`）/ 联系我们（`contact`）** 已经被自动标记为系统关键页。你可以保留这个保护，也可以解除。

## 删除一个页面

页面**不能随意删除**，会卡在三道关：

| 报错提示 | 怎么解决 |
|---|---|
| **该页面已发布，不能删除** | 先把状态改为「已停用」，再删 |
| **这是系统关键页** | 进编辑页关闭「系统关键页」开关，再删 |
| **该页面被 N 个菜单项引用** | 进「菜单管理」找到引用它的菜单项，删除引用，再回来删页面 |

<Aside type="caution">
**已经发布过的页面，删之前请三思**——

- 该网址在外部友链、搜索引擎里都已留下
- 删掉后访问会变 404，影响 SEO 和品牌
- 推荐做法：**先停用 30 天**观察是否还有外部访问，再删

如果实在要换，**用反向代理（Caddy/Nginx）做 301 重定向**到新地址。运维同学知道怎么做。
</Aside>

## 多语言

<Screenshot caption="编辑页右上角的语言 Tab 切换器" hint="展示中文 Tab + 英文 Tab，且英文 Tab 上有「待翻译」状态徽章" />

如果你的站点支持多种语言（如中英文），编辑页**右上角的语言 Tab** 用来切换填不同语言的标题、副标题、正文。

- 中文填好 → 切到英文 Tab → 英文留空？前台访问 `/en/about-us` 时**自动隐藏**这个页面，不会出现"中英混排"
- 英文翻完 → 把英文的「翻译状态」标为 **已完成** → 前台立即上线英文版

**典型工作流（先中文，后英文）**：

<Steps>
1. 默认语言 Tab 下填好中文，标记 **已完成**
2. 切到英文 Tab，把翻译填进去
3. 把英文 Tab 的「翻译状态」标为 **已完成**
4. 主状态切到「已发布」 → 中英文同时上线
</Steps>

**只发中文、英文待翻译**：

英文 Tab 的「翻译状态」保持 **未开始** 或 **进行中**——前台 `/en/about-us` 自动 404 或重定向回中文版，不会出现空页面。

详见 [翻译工作流](/docs/i18n/translation-workflow) 章节。

## 询盘从哪个页面来？

如果某个页面（典型：联系我们、产品落地页）放了询盘表单，所有从这个页面填的询盘**自动绑定到这个页面**。

后台「询盘」列表会显示来源：

```
来源：[页面] 联系我们  →  /contact
```

页面列表也会显示**该页过去 30 天的询盘数**，方便你判断哪些页面"会卖货"。

## 常见问题

### 路径键填错了怎么办？

只要还没发布，随便改。已经发布过、外部已经有人访问了，**强烈建议不改**。如果非改不可：

1. 找运维在 Caddy/Nginx 加一条 301 重定向：旧地址 → 新地址
2. 通知所有外部友链改链接
3. 在 Google Search Console 提交"地址变更"

### 草稿状态会被搜索引擎抓到吗？

**不会**。草稿前台访问就是 404，搜索引擎爬到 404 不会收录。

### 页面正文支持哪些功能？

富文本编辑器支持：

- 标题、列表、引用、加粗、斜体
- 表格
- 图片（拖拽上传）
- 视频（拖拽上传 / 嵌入 YouTube、B 站）
- 链接（可设是否新窗口打开）
- 代码块（带语法高亮，给技术博客用）
- 自定义按钮（"立即询盘"、"立即下载"等 CTA）

### 能给页面加自定义字段吗（比如 hero 大图、CTA 按钮组）？

可以，但需要安装**模型包**。详见 [内容模型扩展](/docs/content/content-models) 章节。

### 我能预览还没发布的页面吗？

可以。编辑页右上角点 **预览**，会用临时地址显示草稿。这个地址只有你能看，未登录用户访问还是 404。
