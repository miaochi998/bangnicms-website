「产品」用来管你**卖给客户、希望客户询盘**的商品 / 设备 / 服务。每条产品在前台有自己的列表卡片 + 详情页。

后台入口：**内容管理 → 产品**

<Screenshot caption="后台「产品管理」列表页全貌" hint="展示列表 + 顶部筛选 + 右上角「新建产品」按钮" />

## 新建一个产品

<Steps>

1. 点列表右上角的 **新建产品**

   <Screenshot caption="新建产品的编辑页" hint="左侧主表单（标题/简介/详情）+ 右侧侧栏（封面图/分类/相关产品/首页精选）" />

2. 填**必填项**：
   - **唯一键**：英文小写、用连字符隔开，决定网址（如 `x500-laser-cutter`）
   - **产品名称**：当前语言下的产品标题

3. 上传**封面图**

   通过封面图选择器上传或选已有图片。封面图会出现在：
   - 前台产品列表卡片
   - 详情页头部
   - 首页精选模块（如果勾选）
   - 相关产品推荐
   - 社交分享时的预览图

4. 选**分类**

   一个产品可以**属于多个分类**（比如一台激光切割机同时属于「工业设备」和「金属加工」）。

   <Aside type="caution">
   分类必须**先在「分类管理」建好**。如果分类下拉框为空，请先去 [分类管理](/docs/content/categories) 建几个分类。
   </Aside>

5. 填**简介**和**详情**

   - **简介**：一句话说清楚是什么，约 50 字。用户在列表页 5 秒决定是否点进来
   - **详情**：富文本编辑器，可插图、视频、表格、按钮

6. （可选）配置**规格 / 图集 / 视频**

   如果你启用了模型包（如系统自带的"工业设备"模型），编辑页右侧会多出几组扩展字段：
   - 图集：上传多张产品图
   - 规格表：键值对（"功率 → 5000W"）
   - 视频：演示视频
   - PDF 资料

   这些都不是产品的"原生字段"——详见 [内容模型扩展](/docs/content/content-models)。

7. **保存草稿** → 翻译其他语言 → **发布**

</Steps>

## 三种状态

跟 [页面管理](/docs/content/pages#三种状态) 一致：草稿 / 已发布 / 已停用。

## 相关产品：手动 vs 自动

每个产品详情页底部最多展示 **3 个相关产品**。两种方式：

**手动指定**

编辑页右侧的「相关产品」选择器，拖拽选 1-3 个产品。

- 优势：精确控制，按你指定顺序展示
- 适合：旗舰产品、需要交叉销售的高客单价商品

**自动推荐**（留空时）

系统按以下规则自动选 3 个：

1. 排除当前产品
2. 仅从已发布的产品中选
3. 按列表排序权重 + 最近更新时间排

- 优势：零维护，自动反映新品
- 适合：单品类站点、产品较少的站点

<Aside type="tip">
**最佳实践**：旗舰产品手动指定，长尾产品留空走自动。
</Aside>

## 相关下载（自动按分类匹配）

产品详情页底部还会自动显示**最多 6 个相关下载**——只要某个 PDF 资料挂在与该产品**相同名字**的分类下，它就会自动出现。

举例：

```
产品「X500 激光切割机」 → 分类「工业设备」
PDF「2026 工业设备产品目录」 → 分类「工业设备」
                ↓
两者通过分类名字自动关联
                ↓
访问 X500 详情页 → 底部自动显示「2026 工业设备产品目录」下载
```

**完全不需要手动绑定**——只要分类名字一致即可。详见 [下载管理 - 与产品自动关联](/docs/content/downloads#与产品自动关联)。

## 首页精选

如果你想让某个产品出现在首页的「精选产品」模块：

<Steps>

1. 编辑产品 → 找到「**显示在首页精选**」开关 → 打开

2. 设置「**精选排序**」（数字越小越靠前）

3. 保存 → 首页精选模块自动展示该产品

</Steps>

<Screenshot caption="首页精选开关与排序字段" hint="编辑页右侧侧栏的「显示在首页精选」开关 + 数字输入框" />

<Aside type="caution">
精选模块**最多展示 6 个产品**，第 7 个开始即使勾了也不会显示。建议运营定期清理，保持精选区的"稀缺感"。
</Aside>

## 删除一个产品

产品**不能随意删除**：

| 报错提示 | 怎么解决 |
|---|---|
| **该产品已发布** | 先把状态改为「已停用」，再删 |
| **该产品被 N 个询盘记录引用** | 询盘是商业记录不能丢——先归档询盘或导出 CSV，再删 |

<Aside type="caution">
**询盘是法律级商业记录**——客户提交的询盘绑定了产品 ID。如果直接删产品，询盘表里会出现"幽灵 ID"导致追溯失败。

**安全删除流程**：

1. 把产品状态改为**已停用**（前台不可见，不再产生新询盘）
2. 等观察期（建议至少 90 天）
3. 已有询盘归档或导出 CSV
4. 再考虑物理删除产品
</Aside>

## 列表页搜索筛选

后台产品列表支持 3 种筛选：

- **关键词搜索**：匹配唯一键和**任意语言**的产品名（不区分大小写）
- **状态**：草稿 / 已发布 / 已停用
- **分类**：仅显示属于该分类的产品

多条件叠加是 AND 关系：状态=已发布 + 分类=工业设备 + 关键词=laser。

<Screenshot caption="产品列表的筛选区" hint="顶部一排筛选控件：搜索框 + 状态下拉 + 分类下拉" />

## 询盘从哪来

如果产品详情页放了询盘表单（系统主题默认开启），所有从该产品页提交的询盘**自动绑定到这个产品**。

后台「询盘」列表会显示来源：

```
来源：[产品] X500 工业激光切割机 → /products/x500-laser-cutter
```

产品列表也会显示**该产品过去 30 天的询盘数**，这是衡量"哪些产品在赚钱"的关键指标。

## 多语言

跟 [页面的多语言](/docs/content/pages#多语言) 流程一致。**注意区分**：

- **全语言共享**：封面图、分类、相关产品、规格表（除非配置可翻译）
- **每种语言独立**：标题、简介、详情、SEO 标题 / 描述

## 常见问题

### 唯一键已经发布了能改吗？

强烈不建议。改会破坏：
- 所有指向该产品的外部链接（友链、社交分享）
- 该产品的搜索引擎排名权重
- 已有询盘记录里的来源链接

如必须改：让运维在反向代理（Caddy/Nginx）加 301 重定向，旧地址 → 新地址。

### 一个产品能放多少图？

- 封面图 1 张（顶层字段，必填）
- 图集 N 张（通过模型包扩展，系统自带模型默认上限 12 张）

### 产品有"价格"字段吗？

**没有原生字段**。BangNiCMS 主要面向 B2B 询盘类站点——价格通常是"询盘后报价"，不公开展示。

如果你的业务确实需要展示价格：

- 简单需求：通过模型包加一个 `price` 自定义字段（详见 [内容模型扩展](/docs/content/content-models)）
- 复杂需求（多档价、阶梯价、币种）：等支持电商的插件

### 能批量导入产品吗？

可以。后台「设置 → 数据导入」支持 CSV 批量导入。**强烈建议**先在测试环境跑一遍确认字段映射无误，再去生产环境。

### 「精选产品」最多 6 个，超出了第 7 个会怎样？

不会显示。建议保持精选不超过 6 个，过多反而稀释品牌焦点。
