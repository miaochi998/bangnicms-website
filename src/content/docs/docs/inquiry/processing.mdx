## 筛选询盘

列表顶部支持**多种筛选**：

- **状态**：仅显示某状态的（如只看"待处理"）
- **时间范围**：今天 / 7 天 / 30 天 / 自定义
- **类型**：产品 / 合作 / 资料
- **来源**：哪个产品 / 落地页
- **国家**：分配区域销售用
- **关键词搜索**：搜联系人 / 公司名 / 邮箱

## 询盘详情

点列表里任一询盘 → 进**详情页**：

<Screenshot caption="询盘详情页" hint="左侧客户基本信息 + 中间需求描述 + 右侧跟进记录时间线 + 顶部状态切换器" />

**详情页内容**：

### 客户信息

- 联系人姓名 / 邮箱 / 电话
- 公司名 / 国家
- 提交时的语言（如 zh-CN）
- 来源页面（带链接，可跳查源产品）
- 来源关键词（如果从搜索引擎来）
- IP 地址 / 浏览器 / 设备

### 需求描述

访客填的"需求描述"原文 + 自动翻译（如果不是销售懂的语言）

### 跟进记录

时间线展示所有跟进动作：

```
2026-04-28 14:30  💬 王销售
"已邮件回复，附产品手册"

2026-04-28 16:00  📞 王销售
"电话沟通 30 分钟，客户对 IS-2026 感兴趣"

2026-04-29 09:00  📧 王销售
"发送报价单"

2026-04-30 10:00  ✅ 王销售
"已成交，订单号 SO-2026-001234"
```

### 内部备注

仅内部可见的备注（不发给客户）：

- 客户预算评估
- 决策人信息
- 竞争对手报价
- 风险提示

### 标签

灵活的分类标签：

- 🔥 高意向
- 💎 大客户
- 🌍 海外
- ⏳ 慢决策
- 自定义

## 状态流转

<Steps>

1. **新询盘**：状态 = **待处理**

2. 销售点 **接单 / 跟进** → 状态变 **跟进中**

3. 销售跟进过程中持续记录跟进动作

4. **结果分支**：

   - **成单** → 状态 = **已成交**（填订单号）
   - **失败** → 状态 = **已关闭**（填关闭原因）
   - **垃圾** → 状态 = **垃圾**（系统过滤后人工确认）

</Steps>

<Screenshot caption="询盘状态切换器" hint="详情页顶部状态选择下拉，包含 5 个选项 + 切换时弹出原因选择 / 关联订单输入" />

## 添加跟进记录

<Steps>

1. **在详情页右侧的跟进记录区** → 点 **+ 添加跟进**

2. **选跟进类型**：
   - 💬 邮件
   - 📞 电话
   - 📅 会议
   - 💼 报价
   - 📦 样品
   - ✅ 成单
   - 其他

3. **填跟进内容**（自由文本）

4. **可选：** 上传附件（报价单、合同等）

5. **保存** → 跟进记录加到时间线

</Steps>

## 批量操作

**列表多选**支持：

- ✅ 批量改状态（待处理 → 跟进中）
- ✅ 批量分配给某销售
- ✅ 批量导出 CSV
- ✅ 批量删除（仅垃圾用）
- ✅ 批量添加标签

**适合**：

- 周一早上把所有"待处理"批量分配给当周值班销售
- 月底把所有"已成交"批量导出做月度报表
- 季度清理"已关闭"的询盘

## 导出 CSV

<Steps>

1. 列表勾选要导出的询盘（或全选 / 全部勾选）

2. 顶部 **批量操作** → **导出 CSV**

3. 选择**字段**：勾选要导出的列（默认全部）

4. **下载** → 浏览器下载 CSV 文件

</Steps>

**用途**：

- 给销售总监看月度数据
- 导入 CRM 系统
- 做客户分析（Excel）

<Aside type="caution">
**导出 CSV 含敏感数据**——

- 客户邮箱、电话、需求
- 内部备注（如果勾选了导出）

**注意**：

- 不要把 CSV 发到公开群
- 不要传到不安全的网盘
- 处理完销毁本地副本
</Aside>

## 删除询盘

**通常不删除**——保留历史询盘有价值（数据复盘 / 销售培训）。

**只删**：

- 明确的**垃圾询盘**（先标记"垃圾"状态，定期统一删除）
- **重复询盘**（同一客户连续提交 5 次相同内容）

**删除是不可逆**——除非有数据库备份，否则删了就没了。

## SLA：响应时长

**B2B 销售的关键指标**：客户提交询盘到首次响应的时间。

| 时长 | 行业评价 |
|---|---|
| **< 1 小时** | 卓越（提升成交率 50%） |
| **1-4 小时** | 良好（行业标杆） |
| **4-24 小时** | 标准 |
| **> 24 小时** | 差（多数客户已转向竞争对手） |
| **> 48 小时** | 失败（基本流单） |

**怎么提升**：

- **邮件实时通知**销售（[通知与跟进](/docs/inquiry/notifications)）
- **企业微信 / 钉钉推送** 让销售随时收到
- **轮班机制**（白天分组、晚上专人）
- **AI 自动回复**（占位回复，让客户知道收到）

## 销售业绩看板

**衡量销售个人业绩**：

| 指标 | 怎么算 |
|---|---|
| **接单数** | 该销售跟进过的询盘数 |
| **成交率** | 成交数 / 接单数 |
| **平均响应时长** | 接单到首次跟进 |
| **跟进次数** | 平均每个询盘跟进多少次 |
| **金额贡献** | 成交订单总金额（如果接 CRM） |

详见 [转化分析](/docs/inquiry/conversion-analytics)。

## 协作 / 转单

如果销售 A 接单后**休假 / 离职**，需要**转给销售 B**：

<Steps>

1. 进询盘详情

2. 点 **重新分配**

3. 选目标销售 B

4. 填**转单原因**（如"销售 A 休假，B 接手"）

5. **保存** → 销售 B 收到邮件 / IM 通知

6. 跟进记录里自动加一条"销售 A → B 转单"

</Steps>

## 多语言 / 多区域

**跨语言询盘**：

- 询盘记录访客提交时的语言（如 zh-CN）
- 销售看到询盘的"客户语言"标识
- **AI 自动翻译需求描述**（如果销售不懂客户语言）
- 销售用客户语言回复（手写 / AI 翻译）

**跨区域询盘**：

- 询盘记录国家 / 地区
- 自动分配给该区域销售（如华南、华北、欧洲、北美）
- 区域销售各自的列表只看自己区域

## 常见问题

### 询盘超过 N 天没人跟进自动提醒吗？

**当前需要插件支持**——基础版 BangNiCMS 不内置 SLA 自动提醒。

可以让开发者扩展：

- 24h 没首次跟进 → 邮件提醒销售
- 48h 没跟进 → 升级提醒主管
- 7d 没跟进 → 自动标记"风险"

详见 [通知与跟进](/docs/inquiry/notifications)。

### 我能给客户标"VIP / 大客户"吗？

可以——通过**标签**功能。详见 [询盘详情 - 标签](#标签)。

### 询盘 → 订单怎么关联？

**当前简单方式**：

- 询盘标"已成交" → 填订单号
- 通过订单号在 CRM 系统查详情

**完整方式**（需要插件）：

- 接 CRM 系统（Hubspot / 销售易）
- 询盘自动同步为 CRM Lead
- 成交后自动同步为 CRM Deal

详见 [通知与跟进 - CRM 集成](/docs/inquiry/notifications#crm-集成)。

### 已关闭的询盘还能"复活"吗？

可以——把状态从"已关闭"改回"跟进中"或"待处理"。**询盘记录永久保留**，状态只是分类。

### 询盘历史能看多久？

**永久保留**——除非手工删除。建议至少保留 **3 年**：

- 监管要求（部分行业）
- 数据复盘
- 销售培训案例
