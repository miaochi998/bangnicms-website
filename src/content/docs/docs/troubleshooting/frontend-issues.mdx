前台是访客看到的——任何问题**直接影响转化**。本节快速诊断。

## 1. 整站白屏

**症状**：访问任何页面都是空白。

**先排除假阳性**：

- 浏览器缓存？硬刷新（Cmd/Ctrl + Shift + R）
- 浏览器扩展屏蔽？无痕模式试
- 网络问题？换网络试
- 设备问题？换设备试

**如果真的整站白屏**：

| 可能 | 怎么验证 | 解决 |
|---|---|---|
| **服务器宕机** | `curl https://yourdomain.com` 看返回码 | 让运维重启服务 |
| **主题崩了** | 后台切回内置主题 | 切走问题主题 |
| **数据库断开** | 看运维日志 | 让运维修数据库 |
| **域名解析问题** | `dig yourdomain.com` | 让运维查 DNS |
| **SSL 证书过期** | 浏览器显示"不安全" | 让运维续证书 |
| **Cloudflare 阻挡** | 看 Cloudflare 状态页 | 暂时绕过 / 等恢复 |

## 2. 部分页白屏 / 报错

**症状**：首页正常，某些页报错。

**可能**：

- 该页内容有问题（如某个字段格式异常）
- 该页用了挂错的插件
- 该页的模板代码有 bug

**怎么排查**：

- 看这一页用了哪些字段 / 插件
- 在测试环境复现
- 简化内容看是否恢复

## 3. 样式错乱

**症状**：布局错位、颜色错、字体异常。

**最常见**：

- 浏览器缓存 → 硬刷新
- 主题升级后未清缓存

**进一步**：

- 主题代码 bug → 联系开发者
- 自定义 CSS 冲突 → 检查"高级 → 自定义 CSS"
- 第三方插件干扰 → 临时停用所有插件看是否恢复

## 4. 改了内容前台没变

**90% 是缓存**：

| 缓存层 | 怎么清 |
|---|---|
| 浏览器缓存 | 硬刷新（Cmd/Ctrl + Shift + R） |
| CDN 缓存（如 Cloudflare） | 让运维清 |
| SSR 缓存（主题层） | 等 1-5 分钟 / 让运维清 |
| 数据库查询缓存 | 通常自动失效 |

**10% 是真没改**：

- 看后台保存是否成功（看到"保存成功"提示）
- 看操作日志确认变更
- 看是否改的是另一个语言版本

## 5. 加载慢

**典型 LCP > 4 秒**：

| 可能瓶颈 | 怎么排查 |
|---|---|
| **Hero 大图** | 看图片大小，> 500 KB 必优化 |
| **第三方脚本** | 浏览器 F12 → Network 看哪些慢 |
| **服务器响应慢** | 看 TTFB（应 < 200ms） |
| **数据库慢查询** | 让运维看慢查询日志 |
| **CDN 不力** | 看 CDN 命中率 |

**优化**：

- 压缩图片（WebP）
- 延迟加载第三方脚本
- 升级服务器配置
- 加 CDN
- 数据库加索引

详见 [性能问题](/docs/troubleshooting/performance-issues)。

## 6. 多语言切换异常

**症状**：切到英文版还是中文。

**可能**：

- 该页**没有英文翻译** → fallback 到默认语言
- URL 没变 → 主题前端 bug
- Cookie 缓存 → 清浏览器 cookie

**详细**：见 [多语言 / SEO 问题](/docs/troubleshooting/i18n-seo-issues)。

## 7. 询盘表单提交后报错

**症状**：填好表单点提交 → 报错。

**可能**：

- **网络断了** → 让用户重试
- **CAPTCHA 验证失败** → 让用户重试
- **后端校验失败** → 看错误提示
- **后端服务挂了** → 让运维查
- **被防垃圾拦截** → 在后台看"垃圾"列表

**测试**：

- 后台「站点设置 → 邮件」点 **测试发送邮件**
- 用无痕模式提交一条测试询盘
- 看后台是否收到 + 邮件是否到

## 8. 图片加载失败

**症状**：图片位置显示 alt 文字 + 破损图标。

**可能**：

- 图片文件**真的不存在** → 媒体库找不到对应文件
- 图片**URL 错** → 后台改对
- **CDN 节点问题** → 等几分钟 / 让运维查
- **跨域问题** → CORS 配置

**具体定位**：浏览器 F12 → Network → 看图片请求的状态码：

- 404 → 文件不存在
- 403 → 权限问题
- 500 → 服务器错
- 超时 → 网络 / CDN

## 9. 视频不能播放

**可能**：

- **格式不支持**（浏览器只认 MP4 H.264 / WebM）
- **文件太大**（几百 MB 加载慢）
- **CDN 不支持视频**
- **手机端流量限制**

**优化**：

- 转 H.264 MP4
- 压缩到 < 50 MB
- 用专业视频 CDN（YouTube / B 站嵌入）

## 10. 搜索结果异常

**症状**：站内搜索框搜不到关键词。

**可能**：

- 内容**没启用搜索索引**
- 索引**还没更新**（新内容刚发）
- 搜索**算法问题**（精确匹配 vs 模糊匹配）

让开发者排查搜索引擎实现。

## 排查工具清单

| 工具 | 用途 |
|---|---|
| **浏览器 F12 Console** | 前端 JS 错误 |
| **F12 Network** | 网络请求 |
| **F12 Performance** | 性能分析 |
| **Lighthouse** | 综合审计 |
| **curl / wget** | 命令行测试 |
| **Web Vitals 扩展** | Core Web Vitals 测量 |

## 何时联系开发者

- 错误日志中含"undefined" / "null"
- 错误堆栈提示主题 / 插件名
- 升级后才出现
- 可在测试环境复现
