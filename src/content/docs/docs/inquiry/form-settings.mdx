询盘表单是访客转化为线索的**入口**——表单设计决定 70% 的转化率。本节教你怎么配。

后台入口：**询盘 → 表单设置**

<Screenshot caption="询盘表单设置面板" hint="左侧字段列表（可拖拽 / 增删 / 必填切换）+ 右侧选中字段的属性（标签 / 占位符 / 校验 / 多语言）" />

## 默认字段

BangNiCMS 默认包含这些字段：

| 字段 | 默认必填 | 用途 |
|---|---|---|
| **联系人姓名** | ✅ | 销售称呼用 |
| **邮箱** | ✅ | 主要联系方式 |
| **电话** | 选填 | 紧急联系 / WhatsApp |
| **公司名** | 选填 | 判断客户规模 |
| **国家 / 地区** | 选填 | 分配区域销售 |
| **需求描述** | ✅ | 了解客户具体需求 |

**自动记录**（不在表单显示）：

- 来源页面（哪个产品 / 文章触发的）
- 来源关键词（如果从搜索引擎来）
- IP 地址 / 浏览器 / 设备
- 提交时间
- 访客当时的语言

## 字段越少，转化越高

**经典 A/B 测试结论**：

- 5 字段表单 → 转化率 ~3%
- 7 字段表单 → 转化率 ~2%
- 10 字段表单 → 转化率 ~1%

**多 1 个字段 = 流失 30% 转化**。

**保留必要的，去掉可选的**：

| 必要 | 选填考虑去掉 |
|---|---|
| 姓名 | 称谓（先生 / 女士） |
| 邮箱 | 邮编 |
| 公司名 | 公司规模 |
| 需求描述 | 行业 |
| | 怎么知道我们的 |

<Aside type="tip">
**B2B 询盘的最少字段** = 4 个：姓名 / 邮箱 / 公司 / 需求。其他都通过销售跟进时问。

**B2C 询盘的最少字段** = 3 个：姓名 / 邮箱 / 需求。
</Aside>

## 自定义字段

可以通过 [模型包扩展](/docs/model-packages/overview) 给询盘表单加字段：

| 字段 | 用途 |
|---|---|
| **预算范围** | 让访客大概说一下，方便销售优先 |
| **采购数量** | B2B 批发场景 |
| **使用场景** | 帮销售匹配方案 |
| **决策时间** | 紧急 / 1 月 / 3 月内 |
| **附件上传** | 让客户传规格 / 设计稿 |

让运维 / 开发者通过模型包给"询盘"内容类型加字段。

## 必填 vs 选填

**怎么决定**：

- **核心信息**（联系不上就没意义）→ 必填
- **筛选信息**（帮销售判断优先级）→ 选填
- **细节信息**（销售跟进时问）→ 不放表单

**别滥用必填**：

- 所有字段必填 = 转化率暴跌
- 加 \* 号让用户害怕

## 字段顺序

**最佳排序**：从简到难

```
1. 姓名（最简单）
2. 邮箱
3. 电话（选填）
4. 公司名（选填）
5. 需求描述（最难）
```

**心理学原理**：访客填了简单字段后**已投入**，更愿意继续填难的。如果一上来就要"详细描述需求"，多数人放弃。

## 表单显示位置

询盘表单可以放多处（取决于主题 + 插件）：

| 位置 | 转化率 | 适合 |
|---|---|---|
| **产品详情页** "立即询价"按钮 → 弹窗 / 跳转 | 高 | 标准做法 |
| **联系我们页面** | 中 | 主要转化页 |
| **首页 CTA 区** | 中 | 引导访客 |
| **Footer 上方** | 低 | 浏览完后的"补刀" |
| **侧边栏浮窗** | 中 | 长内容页面 |
| **退出意图弹窗** | 中 | 流量大站可用 |

通常**至少 3 处**：产品页 / 联系页 / 首页 CTA。

## 多语言表单

**字段定义**全语言一致——**字段标签 / 占位文字 / 提示文字**多语言独立。

举例：

```
英文站：
  Label: "Your Email *"
  Placeholder: "name@company.com"
  Help: "We'll respond within 24 hours"

中文站：
  Label: "您的邮箱 *"
  Placeholder: "name@company.com"
  Help: "我们将在 24 小时内回复"
```

切换语言 Tab 编辑。

## CTA 按钮文案

按钮文字直接影响转化：

| ✅ 好 | ❌ 差 |
|---|---|
| 立即询价 → | 提交 |
| 获取报价 → | 发送 |
| 免费咨询 → | OK |
| 1 分钟获取方案 → | 确认 |

**原则**：

- **动作明确**（询价 / 咨询 / 获取）
- **价值明确**（报价 / 方案 / 资料）
- **降低门槛**（免费 / 1 分钟 / 立即）

## 提交后的反馈

**3 种处理**：

### A. 跳转到"感谢页"

```
URL：/inquiry/thank-you
内容：
  ✓ 您的询盘已提交！
  我们将在 24 小时内联系您。
  在此期间，您可以：
  - 阅读我们的产品手册（链接）
  - 加微信 / WhatsApp 即时联系
```

**优势**：

- 可追踪（GA / 百度统计标记为转化）
- 可二次引导（跟微信 / 阅读资料）

### B. 弹窗显示成功提示

```
✓ 提交成功！
我们将在 24 小时内联系您。
[关闭]
```

**优势**：访客留在原页面继续浏览。

**劣势**：转化跟踪稍麻烦。

### C. 表单原地变成成功提示

```
（原来表单的位置）

✓ 提交成功！
谢谢您的咨询。
```

**优势**：流畅、不打扰。

**劣势**：访客可能没注意到提交成功。

**推荐**：B + 转化跟踪埋点。

## 自动回执邮件

询盘提交后**自动给客户发一封确认邮件**：

```
主题：[确认] 我们已收到您的询盘 - 邦你科技
正文：
  尊敬的张先生，

  感谢您的询盘！我们已收到您关于"工业激光切割机 IS-2026"的需求。

  您的销售顾问将在 24 小时内联系您。
  紧急情况请直接联系：
  电话：+86 ...
  邮箱：sales@example.com

  期待与您合作！
```

**作用**：

- 让访客有"被重视"的感觉
- 防止访客以为没提交成功
- 可附产品手册 PDF（提升信任）

详见 [通知与跟进 - 自动回执](/docs/inquiry/notifications#自动给客户发回执)。

## 字段校验

每个字段**自动校验**：

| 字段 | 校验 |
|---|---|
| 邮箱 | 标准邮箱格式 |
| 电话 | 数字 + - / + ()（宽松） |
| 必填字段 | 不能空 |
| 长度 | 最少 / 最多字符 |
| 文件 | 大小 / 类型（参考 [上传策略](/docs/site-config/upload-media)） |

**校验失败**：

- 字段红边 + 错误提示（如"邮箱格式不正确"）
- 不能提交 → 按钮 disabled

## 何时调整表单

| 时机 | 调什么 |
|---|---|
| **新业务上线** | 加新字段（如新增产品线） |
| **垃圾询盘多** | 加防机器人 / 加蜜罐字段 |
| **转化率低** | 减字段 / 改 CTA 文案 |
| **业务地区扩展** | 加"国家"字段做区域分配 |
| **季节促销** | 改 CTA 强调促销活动 |

## 常见问题

### 我能让产品询盘和合作询盘用不同表单吗？

可以——通过**询盘类型**字段：

- 产品询盘：来自产品页，自动标记类型 = `product`
- 合作询盘：来自合作页，自动标记类型 = `partnership`

不同类型可以**显示不同字段**——通过模型包或主题实现。

### 表单能放视频证言提升转化吗？

可以——在表单上方放"客户证言视频"。视频展示真实客户成交案例，提升表单转化率 20-50%。

详见主题首页模块设计。

### 怎么测试表单是否正常工作？

**至少做 3 个测试**：

1. **正常提交** → 检查邮件通知收到、后台看到
2. **必填字段空着提交** → 应该报错
3. **机器人模拟提交** → 应该被防垃圾拦截

详见 [防垃圾询盘](/docs/inquiry/anti-spam)。

### 多个产品共享一个表单可以吗？

通常**共享一个表单结构**（字段一致），但**自动记录访客提交时的产品**。

后台看询盘时知道这条来自哪个产品 → 销售针对性跟进。
