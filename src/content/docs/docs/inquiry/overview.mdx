「询盘」是 B2B 出海站点最重要的转化指标——访客通过表单提交联系意向（产品询价、合作咨询、资料索取），销售跟进成单。

后台入口：**询盘** 菜单

<Screenshot caption="后台「询盘」列表页全貌" hint="表格列出所有询盘：编号 / 类型 / 联系人 / 公司 / 状态 / 创建时间 / 操作" />

## 完整询盘链路

```
访客访问前台
   ↓
看到产品 / 文章 / 落地页
   ↓
点 [立即询价] / [联系我们] / [获取报价]
   ↓
填写询盘表单（姓名 / 邮箱 / 公司 / 需求）
   ↓ 提交
后端校验（防垃圾、防机器人）
   ↓
保存到数据库
   ↓
[同时] 发邮件通知销售
   ↓
销售在「询盘」后台看到 → 跟进
   ↓
状态更新（待处理 / 跟进中 / 已成交 / 已关闭）
```

## 核心组成

### 1. 询盘表单

通常显示在：

- 产品详情页（"立即询价" 按钮）
- 联系我们页面
- 落地页 CTA 区
- Footer 上方（订阅 + 询盘合并表单）

**字段**通常包括：

- 联系人姓名（必填）
- 邮箱（必填）
- 电话（选填，但建议要）
- 公司名（选填）
- 国家 / 地区（选填）
- 需求描述（必填）
- 来源页面（自动）
- 来源关键词（自动，从搜索引擎来时记录）

详见 [询盘表单设置](/docs/inquiry/form-settings)。

### 2. 询盘后台管理

销售在后台看所有询盘：

- 列表展示（带筛选：状态 / 时间 / 来源）
- 详情页（完整信息 + 跟进记录）
- 状态流转
- 备注 / 标签
- 导出 CSV

详见 [处理询盘](/docs/inquiry/processing)。

### 3. 通知机制

询盘提交后：

- **邮件通知**到销售邮箱（必备）
- **可选**：企业微信 / 钉钉 / Slack 通知（通过插件）
- **可选**：自动给客户发回执邮件

详见 [通知与跟进](/docs/inquiry/notifications)。

### 4. 防垃圾 / 防机器人

每个公开站点都会被机器人攻击 → 必须保护：

- **CAPTCHA / hCaptcha** 验证
- **蜜罐字段**（隐藏字段，机器人会填，人类不会）
- **频率限制**（同 IP 每分钟最多 N 次）
- **关键词过滤**（含恶意链接的自动拦截）

详见 [防垃圾询盘](/docs/inquiry/anti-spam)。

### 5. 转化分析

让运营 / 销售看：

- 哪些产品询盘多
- 哪些来源转化高（搜索引擎 / 直接访问 / 社交）
- 询盘 → 成交率
- 销售响应时长

详见 [转化分析](/docs/inquiry/conversion-analytics)。

## 询盘的状态

通常 4-5 种状态流转：

| 状态 | 含义 | 谁标记 |
|---|---|---|
| **待处理** | 新询盘，未分配 | 系统自动 |
| **跟进中** | 销售已联系 | 销售标记 |
| **已成交** | 询盘转化为订单 | 销售标记 |
| **已关闭** | 询盘无效 / 客户失联 | 销售标记 |
| **垃圾** | 被识别为垃圾询盘 | 系统 / 人工 |

## 衡量指标

B2B 站点的关键转化指标：

| 指标 | 含义 | 行业基准 |
|---|---|---|
| **询盘提交率** | 询盘数 / 访客数 | B2B 0.5-3% |
| **询盘 → 跟进率** | 销售跟进的询盘数 / 总询盘数 | > 80%（响应及时） |
| **询盘 → 成交率** | 成交数 / 询盘数 | B2B 5-20% |
| **垃圾询盘比** | 垃圾数 / 总询盘数 | < 30%（防护有效） |
| **平均响应时长** | 提交到首次跟进的时间 | < 4 小时（及时） |

## 典型 B2B 询盘场景

### 场景 A：精品 B2B 站

- **流量**：每月 5000 访客
- **询盘**：每月 50-100 条（1-2% 转化）
- **垃圾**：每月 20-50 条
- **成交**：每月 5-10 单（5-10% 询盘 → 成交）

### 场景 B：内容驱动 B2B 站

- **流量**：每月 50000 访客（SEO 强）
- **询盘**：每月 250 条（0.5%）
- **特点**：垃圾比例较高（机器人爱抓 SEO 站）
- **成交**：每月 10-15 单（4-6%）

### 场景 C：垂直行业站

- **流量**：每月 1000 访客（小众）
- **询盘**：每月 30 条（3%）
- **特点**：转化率高（精准客户）
- **成交**：每月 6-10 单（20-30%）

## 询盘 vs 订阅 vs 客服

三个概念容易混淆：

| | 询盘 | 订阅 | 客服 |
|---|---|---|---|
| **触发** | 用户主动填表单 | 用户填邮箱 | 用户聊天 |
| **目的** | 转化为订单 | 长期内容推送 | 即时答疑 |
| **数据** | 完整联系信息 | 只有邮箱 | 聊天记录 |
| **跟进** | 销售一对一 | 自动化邮件 | 客服轮班 |
| **后台模块** | 询盘 | 邮件订阅插件 | 客服浮窗插件 |

## 常见问题

### 我可以让访客**不填表单**直接联系吗？

可以——通常配合：

- 客服浮窗（实时聊天）
- 显眼的电话 / 邮箱
- 一键拨号 / 邮件

但**询盘表单仍是关键** —— 为不愿主动联系的访客提供"低门槛"留下信息的方式。

### 一个站点能有多种询盘表单吗（如"产品询价" + "合作咨询"分开）？

可以——通常通过**询盘类型**字段区分。详见 [询盘表单设置](/docs/inquiry/form-settings)。

### 询盘数据能导出给销售用吗？

可以——后台支持**导出 CSV / Excel**。详见 [处理询盘](/docs/inquiry/processing)。

### 我能把询盘自动同步到 CRM（如 Hubspot / Salesforce）吗？

通过插件可以——详见 [通知与跟进](/docs/inquiry/notifications) 中的"CRM 集成"。

### 多语言站点询盘怎么处理？

询盘记录会**自动记录访客当时的语言**（中文站访客填的，标记为 zh-CN）。

销售看到询盘时知道客户用的语言，回复时用对应语言。
