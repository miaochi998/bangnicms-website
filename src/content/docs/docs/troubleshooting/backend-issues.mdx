后台是运营每天工作的地方——任何问题**直接影响生产力**。

## 1. 登录失败

**症状**：输入正确密码也登不上。

**先排除**：

- 大小写 / Caps Lock
- 用户名拼写
- 密码末尾空格

**可能**：

| 原因 | 解决 |
|---|---|
| **密码真的错了** | 让管理员重置密码 |
| **2FA 失败** | 用恢复码 / 让管理员关 2FA |
| **账号已停用** | 让管理员启用 |
| **IP 限制** | 换 IP / 让管理员加白名单 |
| **被锁定**（多次失败） | 等 15 分钟 / 让管理员解锁 |
| **后端服务挂** | 让运维查 |

## 2. 保存失败

**症状**：点保存 → 报错 / 转圈不停。

**先排除**：

- 网络断了 → 看 F12 Network
- 浏览器卡了 → 刷新重试
- 表单字段校验失败 → 看哪个字段红边

**可能**：

| 原因 | 解决 |
|---|---|
| **必填字段空着** | 看错误提示填上 |
| **字段格式错** | 看错误提示改对 |
| **图片 / 文件未上传完** | 等上传完再保存 |
| **数据库写失败** | 让运维查日志 |
| **同时多人编辑冲突** | 让其中一人先保存 |

## 3. 上传失败

**症状**：拖拽 / 选择文件后报错。

**可能**：

| 错误 | 解决 |
|---|---|
| **文件超过上限** | 改小文件 / 让管理员调上限（[上传与媒体设置](/docs/site-config/upload-media)） |
| **文件类型不允许** | 改格式 / 让管理员加白名单 |
| **网络中断** | 重试 |
| **磁盘满了** | 让运维清空间 |
| **文件名含特殊字符** | 改文件名 |

## 4. 按钮无反应

**症状**：点击按钮 → 没动作 / 没提示。

**先看**：

- F12 Console 有没有红字（JS 错误）
- F12 Network 有没有请求（点了没发请求？）

**可能**：

| 原因 | 解决 |
|---|---|
| **JS 报错** | 浏览器扩展冲突 / 主题代码 bug |
| **权限不足** | 让管理员授权 |
| **按钮 disabled** | 看是否有前置条件没满足 |

## 5. 多语言 Tab 切换异常

**症状**：切到英文 Tab 看到的还是中文。

**可能**：

- 该条内容**真的没翻译** → 该字段空 / fallback 到默认
- 浏览器缓存 → 硬刷新
- 后台 bug → 让开发者查

详见 [多语言 / SEO 问题](/docs/troubleshooting/i18n-seo-issues)。

## 6. AI 翻译 / 识别报错

**症状**：点 AI 按钮 → 报错。

**可能**：

| 错误 | 解决 |
|---|---|
| **AI 未启用** | 让管理员配 AI 模型（[邮件通知与 AI 模型](/docs/site-config/email-ai)） |
| **API Key 失效** | 让管理员更新 |
| **配额用完** | 让管理员充值 |
| **网络问题**（中国大陆访问 OpenAI） | 用国产模型或加代理 |
| **AI 服务商故障** | 等等再试 |

## 7. 列表加载慢

**症状**：进产品列表要 10+ 秒才显示。

**可能**：

- 数据量大 + 没加索引 → 让运维加索引
- 数据库性能瓶颈 → 让运维优化
- 网络慢 → 检查网络

**临时方案**：用筛选缩小列表范围。

## 8. 操作了但日志没记录

**症状**：操作日志少了某个操作。

**可能**：

- 该操作**不属于"写"操作**（如登录、查看）→ 不记录
- 操作**失败**（前端转圈但实际没保存） → 不记录
- 日志被人**删除** → 严重，立刻安全审计（不应该能删除）

## 9. 站点设置改了不生效

**症状**：改了某个设置 → 前台没变。

**可能**：

- **没保存**（关闭弹窗时未保存）→ 重新改
- **缓存** → 硬刷新 / 等几分钟
- **改的不是该设置**（同名字段在其他位置） → 看清楚

## 10. 媒体库的图片删不掉

**症状**：点删除 → 报错"被引用，不能删"。

**原因**：BangNiCMS **保护机制**——图片被产品 / 文章引用时禁止删除。

**解决**：

- 后台显示**引用清单**：哪些产品 / 文章在用
- **先解除引用**（改产品 / 文章 不再用这张图）
- 再删除图片

详见 [媒体库 - 删除安全](/docs/content/media)。

## 后台日志位置

让运维查看：

- **应用日志**：BangNiCMS 后端运行日志
- **数据库日志**：慢查询、错误
- **HTTP 日志**：Nginx access / error log
- **审计日志**：操作日志（已暴露在后台）
