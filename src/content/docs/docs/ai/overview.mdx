## AI 配置在哪改

后台入口：**站点设置 → AI 模型**

详见 [邮件通知与 AI 模型](/docs/site-config/email-ai)。需要：

- AI 服务商（OpenAI / Azure / 智谱 / 通义千问 / Claude / Gemini）
- API Key
- 模型 ID
- API 地址

## 谁来配置 AI

**运维**配（涉及 API Key 和密钥），**运营**用（在编辑页点 AI 按钮）。

如果运维还没配 → 后台 AI 按钮会**提示"未启用"**，运营不会以为是 bug。

## AI 不是免费的

每次 AI 调用都按 **token 计费**——开发者 / 服务商收费。

| 任务 | 典型 token 消耗 | 美元成本估算（GPT-4o） |
|---|---|---|
| 翻译 1 篇 1000 字文章 | 2k-3k token | < $0.01 |
| 翻译 1 个产品（500 字） | 1k-1.5k token | < $0.005 |
| 视觉识别 1 张图片 | 1k token | $0.01 |
| 生成 1 个 SEO 描述（150 字） | 500 token | $0.002 |

**全站翻译 100 篇文章到 5 种语言**（500 次调用）：

- GPT-4o：~$3-5（很便宜）
- GPT-4：~$30-50（更贵）
- 国产模型（智谱 GLM-4）：~¥10-30

**保守估算**：中型站点（500 篇内容、5 种语言）翻译总成本 **¥50-300 / 月**——比雇人工翻译便宜 10-100 倍。

## 给 AI 配预算上限

**强烈建议**让运维：

- 在 AI 服务商后台**设月度预算**
- 上限触发后**自动暂停**
- 避免 bug 或恶意调用导致天文账单

详见 [邮件通知与 AI 模型 - 配额管理](/docs/site-config/email-ai#配额管理)。

## AI 能做和不能做

### ✅ AI 擅长

- **翻译**：常用语言对（中英日法德西），质量高
- **批量处理**：100 条产品一晚上跑完
- **结构化生成**：按提示生成 SEO 描述、产品介绍
- **图片描述**：根据图像生成 alt 文本
- **风格润色**：把口语化文字改正式

### ⚠️ AI 一般

- **专业术语翻译**：行业黑话可能不准
- **品牌词翻译**：不知道你的品牌怎么音译
- **创意文案**：能写但缺亮点
- **长文生成**：1000+ 字容易跑题

### ❌ AI 不擅长

- **事实核查**：会"幻觉"生成虚假信息
- **法律 / 医疗内容**：合规风险高
- **小众语言**：方言、冷门语种质量差
- **判断对错**：AI 不能告诉你"这个产品定价合理吗"

## AI 必须人审

不论 AI 多强，**生产环境内容必须人工审核**：

- 翻译结果 → 至少抽检 5%
- SEO 描述 → 看是否符合品牌
- 视觉识别 → 看是否准确描述图片
- 内容润色 → 看是否丢失关键信息

详见 [翻译工作流 - 5 种翻译状态](/docs/i18n/translation-workflow)。

## AI 的隐私边界

**调用云端 AI = 把内容发给第三方**。注意：

- **公开内容**（产品介绍、博客）：用 OpenAI / Claude 没问题
- **半公开内容**（客户名单、内部知识库）：用 Azure OpenAI（企业级合规）
- **机密内容**（合同、客户隐私）：**不要**用云端 AI，用私有化部署模型

如果你公司有数据本地化要求（如金融 / 医疗 / 政府），让运维评估**本地部署**方案：

- DeepSeek 本地部署
- Llama / Qwen 自部署
- 内置向量库的方案

## AI 操作的几个原则

1. **先小后大**：第一次用 AI 处理 5-10 条，看质量后再批量
2. **必有人审**：不要"AI 处理完直接上线"
3. **保留原文**：AI 翻译时永远保留默认语言原文
4. **可回滚**：每次 AI 操作前先备份（多数 AI 操作支持"撤销"）
5. **监控成本**：每周看一次 AI 调用账单
6. **隐私优先**：敏感内容不送云

## 常见问题

### AI 翻译跟人工翻译差距大吗？

**取决于内容类型**：

- 通用业务文案：差距小（GPT-4 与专业译员相当）
- 行业专业术语：人工更准
- 创意文案 / 营销 slogan：人工更好
- 大量长尾内容：AI 性价比远超人工

实操：核心内容人工，长尾用 AI + 人审。

### 我能换 AI 服务商吗（中途从 OpenAI 换到智谱）？

可以——「站点设置 → AI 模型」改服务商即可。

但**已生成的内容质量风格可能有差异**——换服务商后建议**抽测一批**确认质量再大规模启用。

### AI 生成的内容版权属于谁？

法律上有争议——多数 AI 服务商的条款是"**生成内容版权归用户**"。但具体细节看你用的服务商条款。

实操建议：

- 商业用途的关键内容**人工修改**后用（避免完全 AI 生成）
- 重要法律 / 合同等**不要 AI 生成**
- 涉及版权敏感场景（如设计图）**不要 AI 生成**

### AI 能给我推荐"应该写什么文章"吗？

**当前 BangNiCMS 不内置内容选题推荐**——但你可以：

- 用 ChatGPT 等外部工具做选题
- 第三方插件（建设中）

### AI 出错了导致内容损坏怎么办？

**预防**：

- AI 操作前先备份
- 抽样审核
- 用 [翻译状态](/docs/i18n/translation-workflow) 区分"已 AI"和"已人审"

**事后**：

- 多数 AI 操作支持撤销 / 回滚
- 严重情况让运维从数据库备份恢复
