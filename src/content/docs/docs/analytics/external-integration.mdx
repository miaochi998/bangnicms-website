BangNiCMS 内置统计满足**业务核心数据**，但**用户行为细节、关键词排名、热图、A/B 测试**等需要专业第三方工具。本节给接入指南。

## 推荐组合

不同站点类型的最佳工具组合：

| 站点类型 | 推荐工具 |
|---|---|
| **B2B 出海** | GA4 + Search Console + Hotjar |
| **中国大陆** | 百度统计 + 百度站长 + Microsoft Clarity（免费替代 Hotjar） |
| **跨国双市场** | GA4 + 百度统计 + Search Console + 百度站长 |
| **隐私敏感** | Plausible / Matomo（自建）+ 内置 |

## Google Analytics 4

**最重要的免费分析工具**——95% 的全球站点都用。

### 接入流程

<Steps>

1. **注册 GA4 账号** → 创建属性

2. **拿到 Measurement ID**（格式：`G-XXXXXXXXXX`）

3. **后台「插件 → Google Analytics」** 配置：
   - Measurement ID
   - 是否启用增强测量
   - 是否匿名化 IP
   - 是否追踪登录用户（建议关）

4. **保存** → 前台所有页面立即追踪

5. **GA4 后台**实时报告 → 看到自己访问数据，确认接入成功

</Steps>

<Screenshot caption="Google Analytics 配置面板" hint="字段：Measurement ID 输入框 + 增强测量开关 + 匿名 IP 开关 + 测试连接按钮" />

### GA4 看什么

**首选 5 个报告**：

- **首页 / 报告 / 实时**：当前在线人数
- **获客 / 流量获取**：来源细分
- **互动 / 页面和屏幕**：内容表现
- **转化**：自定义事件追踪（询盘提交、CTA 点击）
- **用户**：受众画像

### 自定义事件

让运维 / 开发者埋点关键事件：

| 事件名 | 触发 | 价值 |
|---|---|---|
| `inquiry_submit` | 询盘表单提交成功 | 核心转化 |
| `cta_click` | CTA 按钮点击 | 漏斗中段 |
| `download_pdf` | 下载产品手册 | 高意向 |
| `video_play` | 播放产品视频 | 兴趣信号 |
| `language_switch` | 切换语言 | 受众语言分布 |

## Google Search Console

**SEO 必接** —— 看真实搜索数据。

### 接入流程

<Steps>

1. **注册 Search Console** → 添加资源（你的域名）

2. **验证所有权**——4 种方式：
   - HTML 文件上传（让运维放到根目录）
   - DNS 记录（让运维配 TXT 记录）
   - HTML 标签（粘到主题 `<head>`）
   - GA 关联（最简单——如果你已接 GA4）

3. **提交 sitemap**：`https://yourdomain.com/sitemap.xml`（BangNiCMS 自动生成）

4. **等 1-2 周** → 数据开始显示

</Steps>

### Search Console 看什么

- **效果**：哪些关键词带流量、CTR、平均排名
- **覆盖**：哪些页被收录 / 未收录及原因
- **核心网页指标**：Core Web Vitals
- **链接**：外链清单
- **手动操作**：是否被 Google 惩罚

详见 [SEO 数据看板](/docs/analytics/seo-dashboard)。

## 百度统计

**中国大陆站点必接**。

### 接入流程

<Steps>

1. **注册百度统计**（tongji.baidu.com）

2. **添加站点** → 拿到**统计代码**（一段 JS）

3. **后台「插件 → 百度统计」** 配置：
   - 直接粘 JS 代码
   - 或填**站点 ID**（`xxxxxxx`）

4. **保存** → 前台追踪

5. **24 小时后**百度统计后台开始显示数据

</Steps>

### 百度统计 看什么

- **趋势分析**：流量趋势
- **来源分析**：搜索词、外链
- **页面分析**：着陆页、退出页
- **访客分析**：地域、设备
- **转化分析**：自定义事件

## 百度站长平台

**百度 SEO 必接**——相当于百度的 Search Console。

### 接入流程

<Steps>

1. **注册百度站长**（ziyuan.baidu.com）

2. **添加站点 + 验证**

3. **提交 sitemap**

4. **配置数据接入**：
   - **死链提交**：让百度知道哪些页没了
   - **链接主动推送**：内容发布后自动推 URL
   - **API 推送**（让运维配）

5. **等 1-2 周** → 数据显示

</Steps>

### 百度站长 看什么

- **流量与关键词**：百度关键词排名
- **抓取诊断**：百度爬虫能否访问
- **索引量**：被百度收录的页数
- **移动适配**：手机端 SEO

## Hotjar / Microsoft Clarity（行为录像）

**用途**：录制用户实际操作，看**他们怎么用你的站**。

### Hotjar

- 付费（有免费版）
- 提供：录像、热图、表单分析、用户问卷

### Microsoft Clarity

- **完全免费**（强烈推荐）
- 提供：录像、热图
- 中国大陆访问稳定

### 接入流程

<Steps>

1. 注册 Clarity / Hotjar 账号

2. 拿到追踪 ID

3. 在主题"自定义 JS"里粘嵌入代码

4. 24-48 小时数据开始显示

</Steps>

### 看什么

- **用户录像**：看真实用户在你的站怎么操作
- **热图**：哪个区域被点击最多 / 滚动最多
- **死点击**：用户点了不可点击的元素（设计混淆）
- **愤怒点击**：用户连续快速点同一处（功能不工作）
- **表单分析**：哪个字段被放弃最多

## Plausible / Matomo（隐私友好）

如果你**不想用 Google**（GDPR / 数据自主）：

### Plausible

- 付费云端
- 极简、隐私优先（不用 cookie）
- 无需 cookie 同意

### Matomo

- 可**自部署**（数据完全自主）
- 功能与 GA4 相当
- 适合企业 / 政府

### 接入

类似 GA—— 拿追踪 ID + 配到 BangNiCMS 插件。

## 数据交叉验证

**为什么数据对不上**：

| 工具 A vs B | 差异原因 |
|---|---|
| GA4 vs 内置 | GA4 受广告屏蔽影响、内置不受 |
| GA4 vs Search Console | GA = 浏览器、SC = 搜索引擎计 |
| 内置 vs 百度统计 | 中国 / 海外网络差异 |
| 当日 vs 次日 | 数据延迟 24-48h |

**通常**：

- 不要纠结绝对数字
- 看**趋势** + **相对比例**
- 用**单一可信源**做决策（比如 GA4 作为主）

## 性能影响

**追踪脚本对性能的影响**：

| 工具 | LCP 影响 | 体积 |
|---|---|---|
| GA4 | 极小 | ~50 KB |
| 百度统计 | 极小 | ~30 KB |
| Hotjar | 中 | ~150 KB |
| Clarity | 极小 | ~50 KB |

**最佳实践**：

- **延迟加载**追踪脚本（页面交互后再加载）
- **并行加载**而非串行
- **CDN 加速**

让运维 / 开发者优化。

## Cookie 同意（GDPR / CCPA）

**服务欧盟 / 美国加州必须有**：

- Cookie 同意横幅
- 用户**先同意**才启动追踪

详见 [常见插件类型 - Cookie 同意横幅](/docs/plugins/common-types#7-cookie-同意横幅cookie-consent)。

## 何时调整工具

| 时机 | 调什么 |
|---|---|
| **新站上线** | 接 GA4 + Search Console（最少必备） |
| **流量起来后** | 加 Clarity / Hotjar 看用户行为 |
| **国际扩展** | 加 Search Console（海外）/ 百度（中国） |
| **隐私升级** | 评估 Plausible / Matomo |

## 常见问题

### 我能同时接多个统计工具吗？

可以——但**别超过 3 个**：

- 加载多套脚本拖慢前台
- 数据相互矛盾难以归因
- 维护成本高

**典型组合**：GA4 + Search Console + Clarity（3 个就够）。

### Search Console / GA 数据延迟多久？

- **GA4 实时**：秒级
- **GA4 标准报告**：4-24 小时
- **Search Console**：1-3 天延迟

### 我能接自建 BI 系统（如 Power BI / Tableau）吗？

可以——通过：

- 让运维**直连数据库**让 BI 工具读
- 或定期**导出 CSV** 上传 BI

**安全建议**：BI 用**只读账号**连数据库，避免误删。

### 中国大陆能用 Google Analytics 吗？

**理论可以**——但：

- GA4 脚本在中国大陆**有时加载慢**
- 数据**收集到 Google 服务器**（合规风险）

**建议**：

- 中国大陆站**主用百度统计**
- GA4 作为辅助（看海外流量）

### 我能不用任何统计追踪吗？

**技术上可以**——但你会失去：

- 流量数据
- 用户行为洞察
- SEO 数据
- 转化追踪

**强烈建议**至少接 **Search Console**（免费、隐私好、SEO 必备）。
