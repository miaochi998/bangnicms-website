## BangNiCMS 技术栈

| 层 | 技术 |
|---|---|
| **前台 / 主题** | Astro + React + TypeScript |
| **后台 / 管理** | Next.js + React + TypeScript |
| **后端 / API** | NestJS + TypeScript |
| **数据库** | PostgreSQL（默认） / MySQL |
| **ORM** | Prisma |
| **存储** | 本地文件系统 / OSS / S3 |
| **包管理** | pnpm Workspaces |

## 学习路径

### 新手（第一次接触 BangNiCMS）

```
1. 先用 BangNiCMS 当用户体验一遍
   ↓
2. 看运营文档了解功能
   ↓
3. 看本组的 [API 总览]
   ↓
4. 搭建本地开发环境
   ↓
5. 先做小修改：改主题颜色 / 加 1 个字段
```

### 中级（熟悉 React / TypeScript）

```
1. 看 [主题开发] 完整文档
   ↓
2. fork 内置主题修改
   ↓
3. 打包 + 安装到自己站点
   ↓
4. 学 [插件开发]
```

### 高级

```
1. 阅读官方主题源码
   ↓
2. 写复杂插件（如 CRM 集成）
   ↓
3. 贡献到官方
```

## 开发原则

### 1. 不破坏向后兼容

升级 BangNiCMS 时，**老的主题 / 插件应该仍然工作**。

### 2. 配置 vs 硬编码

把可变的配置**暴露给运营**，避免硬编码（详见 [插件配置](/docs/plugins/configuration)）。

### 3. 多语言友好

所有用户可见文案**支持 i18n**——不要硬编码"Submit"按钮。

### 4. 性能优先

延迟加载、CDN、缓存——做好性能。

### 5. 安全优先

- API Key 不放代码
- 用户输入**先校验**
- XSS / CSRF 防护
