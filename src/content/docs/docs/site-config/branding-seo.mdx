「品牌信息与 SEO」是站点设置里最先要做的——它决定**浏览器标签、搜索引擎结果、社交分享、邮件签名**用什么文字和图标。

后台入口：**站点设置 → 基本信息**（首屏第一组）

<Screenshot caption="站点设置 → 基本信息折叠面板" hint="展示所有品牌字段：站点名 / 副标题 / 描述 / 关键词 / Logo / favicon" />

## 6 个核心字段

| 字段 | 用在哪 | 长度建议 |
|---|---|---|
| **站点名** | 浏览器标签、Header Logo 旁边、邮件签名、SEO 默认标题 | 5-30 字 |
| **副标题** | Header Logo 下方的小字（如"专业 B2B 内容管家"） | 8-50 字 |
| **站点描述** | SEO `meta description`、社交分享卡片摘要 | 80-160 字 |
| **关键词** | SEO 关键词字段（影响有限，详见下文） | 3-5 个词 |
| **Logo** | Header 显示 + 邮件签名 + 社交分享 | 见下文 |
| **favicon** | 浏览器标签的小图标、收藏夹图标 | 见下文 |

## 站点名（多语言）

这是**最常被搜索引擎和用户看到**的字段——必须用心填。

**好的站点名 vs 差的站点名**：

| ✅ 好 | ❌ 差 |
|---|---|
| 「邦你 CMS」（简洁、品牌化） | 「专业的 B2B 出海内容管理系统平台 - 邦你 CMS」（堆砌关键词） |
| 「BangNiCMS」（英文版直译） | 「China's Most Professional Content Platform」（虚假宣传） |

<Aside type="caution">
**不要在站点名里堆 SEO 关键词**——

- 现代搜索引擎（Google / Bing）能识别"标题堆砌"，反而会**降权**
- 用户看到一长串关键词反而觉得不专业
- **专业建议**：站点名 = 你的品牌名（5-15 字），关键词放在「描述」字段里
</Aside>

## 副标题

显示在 Header 站点名旁边，给品牌做一句话定位：

- 中文示例：「专业 B2B 内容管家」、「跨境出海全链路解决方案」
- 英文示例：「Your B2B content companion」、「Cross-border content solutions」

副标题可选，留空时 Header 只显示站点名。

## 站点描述（SEO 关键）

这就是搜索引擎结果里**站点名下面那段灰色文字**——决定用户搜到你时**会不会点进来**。

**两种典型写法**：

**方式 1：业务说明 + 价值主张**

> "邦你 CMS 是面向 B2B 出海企业的内容管理系统，支持多语言内容创作、SEO 优化、AI 翻译辅助、询盘转化跟踪——让你的内容运营效率提升 3 倍。"

**方式 2：场景化引导**

> "30 分钟搭建你的多语言企业站。开箱即用的产品、文章、下载、询盘模块——让市场团队专注内容，技术细节交给我们。"

<Aside type="tip">
**SEO 描述的 5 个原则**：

1. **80-160 字**——超过会被搜索引擎截断
2. **第一句最重要**——把**核心价值**前置
3. **包含 1-2 个关键词**——但要自然，不能堆砌
4. **加行动词**——"提升 3 倍"、"30 分钟搭建"等量化语言
5. **避免空话**——"全球领先"、"最专业"对 SEO 无益
</Aside>

## 关键词（重要性已下降）

**这个字段曾经是 SEO 重要信号，但现在不是了**：

- Google 自 2009 年公开声明 `meta keywords` 不影响排名
- Bing / Yandex / 百度也基本一致
- **但**仍然建议填——某些垂直搜索引擎、企业站工具会读它

**怎么填**：

- 3-5 个核心关键词，**英文逗号**分隔
- 中文示例：`B2B 出海, 内容管理, 多语言 SEO, AI 翻译`
- 英文示例：`b2b cms, content management, multi-language seo, ai translation`

## Logo

Logo 出现在前台 **Header 左上角** + 邮件签名 + 社交分享。

**上传规格建议**：

- **尺寸**：宽度 200-400px，高度 40-80px（横版 Logo）
- **格式**：PNG（透明背景）或 SVG（可缩放）
- **大小**：< 100 KB
- **背景**：透明（PNG）或纯色（如果主题需要）

<Steps>

1. 在「基本信息」面板找到 **Logo** 字段

2. 点 **选择 / 上传**

   <Screenshot caption="Logo 上传组件" hint="可选：从媒体库选择已有图片 / 拖拽上传新文件 / 输入外部 URL" />

3. 选已有图片或上传新文件 → 自动落到媒体库

4. **保存设置** → 前台立即生效

</Steps>

<Aside type="tip">
**深色 / 浅色主题适配**：

如果你的主题支持深浅模式（系统主题默认支持），建议准备**两个版本的 Logo**：

- 深色主题：白色 / 浅色 Logo
- 浅色主题：黑色 / 深色 Logo

主题会根据当前模式自动选用。具体在主题设置里配置（详见 [主题](#) 章节，建设中）。
</Aside>

## favicon

favicon 是**浏览器标签左侧的小图标** + 收藏夹图标 + 桌面快捷方式图标。

**规格**：

- **尺寸**：32×32 或 64×64（多数浏览器）
- **格式**：PNG / ICO / SVG
- **大小**：< 50 KB
- **设计**：高对比度、识别度高（标签栏只有 16-20px 显示空间）

**典型做法**：把 Logo 简化为单字 / 图形 → 转 ICO 或 PNG → 上传。

## 多语言品牌信息

**全语言共享**：

- Logo
- favicon

**每种语言独立**：

- 站点名（中文「邦你 CMS」，英文「BangNiCMS」）
- 副标题
- 站点描述
- 关键词

**操作**：站点设置页顶部有**语言 Tab 切换器**——切换 Tab 填每种语言的版本。

<Screenshot caption="站点设置的语言 Tab" hint="切换中英文 Tab，下方品牌字段显示该语言的填写状态" />

**没翻译的语言**：

- 副标题 / 描述 / 关键词留空 → 前台显示**默认语言**的版本作为 fallback
- **站点名永远必须填** → 否则浏览器标签会显示"未命名站点"

## 何时改这些字段

| 字段 | 改动频率 | 改的时机 |
|---|---|---|
| **站点名** | 极少改 | 公司改名 / 品牌升级 |
| **副标题** | 偶尔改 | 业务方向调整、新主推产品上线 |
| **描述** | **可以经常优化** | A/B 测试不同描述 → 看搜索点击率 |
| **关键词** | 偶尔改 | 业务关键词演进 |
| **Logo** | 极少改 | 品牌视觉升级 |
| **favicon** | 极少改 | 配合 Logo 升级 |

## 常见问题

### 描述字段写多长合适？

**80-160 字**最佳。各搜索引擎的截断长度：

- **Google**：约 160 字符（中文约 80 字）
- **Bing**：约 200 字符
- **百度**：约 75 字符

**保守做法**：写 80 字以内，确保所有搜索引擎都不截断。

### 改了 Logo 但前台没变？

90% 是**浏览器缓存**：

- 硬刷新页面（Cmd/Ctrl + Shift + R）
- 或清浏览器缓存

如果还不行：

- 检查保存是否成功（页面顶部应有"保存成功"提示）
- 检查 Logo 字段是否填的是有效 URL

### 多语言站点的 Logo 能用不同图片吗？

**默认不行**——Logo 字段是全语言共享。

如果业务真的需要（如不同语言区用本地化设计 Logo），需要：

- 在主题模板里硬编码"按当前语言切换 Logo URL"
- 或通过插件扩展

详见 [主题开发](#) 章节（建设中）。

### favicon 和 apple-touch-icon 有什么区别？

- **favicon** — 浏览器标签 / 收藏夹（PC 端）
- **apple-touch-icon** — iOS 添加到主屏幕时的图标（180×180 像素）

当前 BangNiCMS 只有一个 favicon 字段。如果你需要专门的 iOS 图标，可以：

- 让运维在主题里加 `apple-touch-icon` 标签
- 或在前端 `<head>` 里手动加（详见主题文档）

### 站点描述能在每个产品 / 文章页单独覆盖吗？

可以——单条内容（产品 / 文章 / 页面）的 SEO 描述字段会**覆盖**站点设置里的默认描述。

详见 [产品管理](/docs/content/products) / [文章管理](/docs/content/articles) 中的 SEO 字段说明。
